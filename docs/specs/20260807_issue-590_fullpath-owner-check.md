### ラベル追随の欠落を機械で止めた

テキストの追随では 3 度目が起きる。よって `scripts.repo.test.js` に
**`check-cross-repo-refs.js` のソースから `kind:` リテラルを静的に集め、全 kind が
`CROSS_REPO_REF_LABELS` に在ることを突き合わせる**テストを常設した。
**フィクスチャ列挙にしなかった理由**: 新しい kind を足したとき、フィクスチャ方式だと
その kind 自体を書き忘れて素通りする。静的走査なら自動的に対象へ入る。

変異試験（`owner` ラベルを削除）で **`AssertionError: … CROSS_REPO_REF_LABELS に無い kind: owner`**
を実測した。`scripts/README.md` は**列挙を落として**「型の一覧は検査器冒頭が単一情報源」へ寄せた
（列挙をもう 1 本増やすのは本 PR の方針と矛盾するため）。
