# 作業仕様書: 記録凍結の射程を記録種ごとに分ける

## 1. 起点となる ID（トレーサビリティ）

- **無採番 `NFR`**（文書統制。計画側の非機能要件表に当たる番号が無い。[IADR-0179](../adr/IADR-0179_unnumbered-nfr-for-meta-work.md) 決定 1）
- 起票: [#803](https://github.com/endazon/microservices-platform/issues/803)（波 6 末クロス監査 Y-9 が検出）
- 裁定: **planning#387**（利用者 2026-08-16）。計画側の反映は
  [planning#389](https://github.com/endazon/project-planning/pull/389)

## 2. 何が起きていたか

**同じ波の中で、2 つの記録種が逆向きの規則で運用された。**

| PR | やったこと |
| --- | --- |
| #800（`1cdbf1e3`） | `feedback/` の本文追記を「規約違反」として **3 ブロック撤去した** |
| #789（`bd90c799`） | `status: done` の作業仕様書へ **112 行の本文追記を加えた** |

裁定 planning#369 が `IADR-0191` 決定 2 の射程を①（frontmatter の二重記述）へ絞ったとき、
**明文は `feedback/` についてのみ**であった。結果、`docs/specs/` は一律不可のまま残り、
**「筋は通るが条文が禁じている」状態が放置された**（`ceda9d70` / #770 に続く**同型 2 回目**）。

## 3. 裁定と、実装側に委ねられた部分

**planning#387 は案 C を採った** —— 記録の種類ごとに別の射程を定めてよい。

> 実装リポジトリ固有の記録（`docs/specs/` 等。**計画リポジトリに対応物は無い**）の射程は、
> **実装側が自分の規約として定める**。

**計画側が決めたのは「分けてよい」までである。** 次の 2 つは本 PR が決めた。

### 3-1. `docs/specs/` の射程

| 型 | 可否 | 理由 |
| --- | --- | --- |
| **書式つきの経過追記**（`［YYYY-MM-DD 追記 / #NNN］` で「その後どうなったか」） | **可** | 作業仕様書は「着手前に書いた計画」であり、**結末を同じ場所で読めることに価値がある**。書式が付く限り、当時の本文と後の追記は読み分けられる |
| **既存本文の書き換え・削除** | **不可** | 当時そう書いたという史実が消える |
| **frontmatter の状態欄を本文で言い直す追記**（①型） | **不可** | 同じ事実が 2 箇所にあり、片方が腐る |
| **状態の進行**（frontmatter の書き換え） | **不可**（従前どおり） | 当時の判断を変える（`IADR-0166` 決定 2 の元の表） |

### 3-2. #789 の 112 行は**残す**

**書式を守っており、上の 1 行目に当たる。** 移設すると #454 の継続作業を追う者が
2 ファイルを行き来することになる。

### 3-3. 機械検査は置かない

計画側 planning#313 の「**検査器にしてよいのは例外が無いと言い切れる規則だけ**」に照らすと該当しない。
「書式を守っているか」は機械で見られるが、「**その追記が経過なのか、書き換えの偽装なのか**」は見られない。
**書式だけを検査すると、書式さえ付ければ何を足してもよい運用に倒れる。**
→ **人が守る規則として必読規約へ置いた。**

### 🔴 読書予算 —— **PR #847 との合算に注意**

本 PR 単独では **50,474 B（98.6%）**。しかし **PR [#847](https://github.com/endazon/microservices-platform/pull/847) が
`CLAUDE.md` へ +261 B を入れている**。

**両方がマージされた後の合算は 50,735 B（99.1%）・余白 465 B である。**

**どちらのブランチの CI もこれを検出できない** —— それぞれの branch では相手の変更が見えないためである。
**後にマージされる側が rebase 後に再測すること。**

当初 +698 B で書いた射程表を、この合算を実測してから **+342 B へ圧縮した**（表 → 箇条書き 4 行）。
規範は 1 つも落としていない。
