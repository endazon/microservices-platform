## 判断

### ★★ 判断 1: **節を出すとき、見出しはスタブとして残す**

**確定済み記録は「ファイル ＋ 節名」で引いている**（軸 c）。**節名ごと消すと、その引用が指す先が消える。**
`IADR-0166` と `.claude/rules/traceability.md` 自身が**確定済み記録の書き換えを禁じている**ため、
**引用側を直す手段が無い**（#684 判断 1 と同じ構造。あちらは**パス**、こちらは**節名**）。

**したがって、出した節の見出しは 1〜2 行のスタブとして入口に残し、別紙を指す。**

| | |
| --- | --- |
| 見出し | **残す**（確定済み記録の引用が生きる） |
| 本文 | **別紙へ出す** |
| スタブの中身 | **いつ読むか ＋ 別紙へのリンク** |

> **★ スタブは「妥協」ではない。** IADR-0172 決定 4 が要求する**導線そのもの**である。
> **1 つの手当てで「引用の生存」と「導線」の両方を満たす。**

### 判断 2: **出すのは説明・仕様詳細のみ。規範は入口に残す**

**IADR-0172 決定 3 は段 1 を「約 11,000B」と見積もっていた。楽観である。**

**規範を別紙へ出すと、書く側は「別紙を読まなかった」だけで CI に落ちる。**
機械が止めるのは事実だが、**止まってから読むのでは手戻りである。**
**「機械が強制しているから読まなくてよい」が成り立つのは説明の部分だけ**である。

| 区分 | バイト |
| --- | ---: |
| **出す** —— PR タイトルの検査 7,954 ＋ 除外する自動コミット 442 | **8,396** |
| 入口に残す —— 前文 2,172 ＋ 採番衝突 794 ＋ クロスリポ修飾 2,186 | 5,152 |
| **スタブで戻る分**（見出し 2 つ ＋ 導線） | **−約 300** |

**段 1 の実効は約 8,100B**（見積り 11,000B より小さい）。**着地は実測して記録する。**

### 判断 3: **別紙は `docs/` 配下に置く**

`.claude/rules/traceability.md:164` が **`../../docs/specs/...` を相対リンクで指している**（実測）。
**`.claude/rules/` から `docs/` を指す形は既に成立している。**

### 判断 4: **`paths` は使わない**

IADR-0172 決定 5 のとおり、**`paths` は「どのファイルを編集するか」でしか条件を書けない。**
**「コミットするとき」はファイルパスで表現できない**ため、この節には効かない。
