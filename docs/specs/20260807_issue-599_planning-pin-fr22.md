### 2. **FR-19 / FR-20 の着手ゲートが部分解除された**（本作業の最大の変更）

planning#250 の裁定（質問票 第15回 Q5・Q6）が **INDEX 決定 33** と **ADR-0037 の「着手可否の注記」**として着地した。

> **FR-19 / FR-20 は、SC-19 の本文編集導線を除いて着手してよい。** ADR-0037 の決定 1〜20 はいずれも覆らず、
> 覆り得るのは前提として引く「個人資料の本文編集手段を Wiki.js とする」裁定（planning#74）だけである。
> **前提検証（Wiki.js の個人スコープ可視性制御）は #449 から切り出して先に単独で実施する**
> —— #449（再実装の大玉）の完了を待つと、planning#237 で解いたゲートが別の形で復活するためである

**ADR-0037 が [[IADR-0119]] を名指ししている。**

> 実装側 `IADR-0119` が定める着手条件（前提 ADR が `Accepted`）は、本注記により**範囲を限って満たされる**。

| | 覆り得るか | 着手可否 |
| --- | --- | --- |
| ADR-0037 決定 1〜20（転送方式・同期・削除と保持・通知・競合解決・監査ログ・トークン・容量・版履歴・完全削除） | **覆らない** | **着手可** |
| SC-20（Obsidian 連携設定）全体 | **覆らない** | **着手可** |
| **SC-19 の「本文を編集（Wiki.js）」導線ただ 1 つ** | **覆り得る** | **保留継続** |

**当初「[[IADR-0119]] へ日付つき追記を入れる（決定 2 の条件は変えない）」と設計したが、これは誤りだった。**

[[IADR-0119]] **決定 6 後段**が本件を名指しで規定している。

> **前提が確定しないまま着手が必要になった場合は、本 IADR を改める新 IADR を起票する
> （本 IADR の本文は書き換えない）。**

**前提検証は未了のままである** —— 計画は検証を完了させたのではなく、**覆り得る範囲を絞り込んだ**。
つまり決定 2 の条件（前提検証の完了）は満たされておらず、**条件そのものが置き換わった**。
#586 の第 1 追補は「条件が満たされたことの記録」なので追補で正しかったが、**本件は別種である。**

**したがって [[IADR-0142]] を起票した**（マージ前クロス監査が検出）。

### 3. レンジを守る機械検査 2 本が落ちた —— **着手前には対象と見込んでいなかった**

pin を進めた時点で、**レンジの件数を固定しているラチェット 2 本が正しく落ちた**。

```console
scripts/scripts.repo.test.js:755        AssertionError: 計画レンジの件数が変わった: 54 !== 53
scripts/check-test-traceability.js:395  FAIL 実ファイル: … 計画 ID 53 件を読める（actual: 54）
```

**これは #472 が塞いだ fail-open の網であり、実際に機能した最初の例である**
（`.claude/rules/traceability.md` の「レンジは監査 / `trace-check` の突合基準であり、
古いままだと新 ID の参照を『存在しない ID』と誤検出する」という記述を機械で守るもの）。

**実測に合わせて 54 へ上げ、「先に数だけ合わせるとレンジの追随漏れを検出する唯一の網が消える」旨を
コメントで残した**（`.claude/rules/traceability.md` と**同時に**動かすこと）。

> **母集合の引き直しで見つけたのではなく、検査が落ちて見つけた。** 軸 1（古い FR レンジ）の走査では
> この 2 ファイルが**ヒットしていた**が、「レンジを引数として持たない」と判断して対象外に振っていた。
> **実際には期待値として件数を持っていた** —— これも「ファイルは母集合に入っていたが中身を読み切らなかった」型である
> （[[IADR-0141]] 決定 1 の追記）。**本 PR でも 1 度踏んだことを記録する。**

**この分類変更により、本 PR は [[IADR-0141]] 決定 4 の「機械検査を新設・改修する」に当たる**
（着手時の見込みは「記録の追随のみ」だった）。**分類は件名ではなく差分から決める**という同決定の
規定どおり、**差分が確定した時点で分類を当て直した。**
