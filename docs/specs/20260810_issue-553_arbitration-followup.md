## 判断

### 判断 1: **planning#198 の 22 箇所を追随させる**（IADR-0128 だけではない）

#553 は IADR-0128 への追記を挙げているが、**同型は 22 箇所ある**。
IADR-0128 / IADR-0127 / IADR-0042 / IADR-0039 / `docs/adr/README.md` /
`docs/screens/SC-05・06・07` / 画面のソースコメントに散っている。

**日付つき［追記］で残し、元の記述は消さない**（このリポジトリの作法。先例は IADR-0117→0056 等）。
**「当時は裁定待ちだった」という事実自体は正しい記録**であり、消すと判断の経緯が読めなくなる。

### 判断 2: **planning#197 の 12 箇所は論点ごとに判定する**

**「planning#197 の裁定待ち」を機械的に置換しない。** 論点が
「表示名」なら解決済み、「対象範囲フィルタ」なら #539 で実装済み、と着地が違う。
**1 件ずつ開いて、その箇所が何の論点を指しているかで決める。**

### 判断 3: **planning#306 の 2 箇所と、条件付きの 10 箇所は触らない**

- planning#306（`IADR-0044` / `DocumentEndpoints.cs`）は**本当に裁定待ち**である。
- 「着手時に判断し**必要なら**計画へ裁定を仰ぐ」（IADR-0139 / 0151 / 0152 / `DataSourceSyncService.cs`）は
  **将来の条件付き**であって陳腐化していない。

**除外した理由をここに書く**（母集合の規則 6）。

### 判断 4: **Part 2 は保留コメント 2 件の更新に限る**（Storybook は触らない）

`Primitives.stories.tsx` は **#541 が既に正しい値にしてある**。**触る必要が無い。**

`confidentiality.ts` / `attributes.ts` の保留理由（「計画内で表示名が揺れているため生値を出す」）は
**もう成り立たない**ので、**裁定で確定したこと**と**写像の実装先（#541）**へ書き換える。
**写像そのものは本 PR で実装しない**（#553 が明示的にそう指示している）。

> **`@platform/ui` に表示文言を持たせない規約（[[IADR-0125]] 決定 1）との整合**:
> #553 は「ストーリーへ本物の文言を書くこと自体が規約に触れないか」を判断せよと言うが、
> **既に #541 が本物の文言で書いており、その判断は済んでいる** —— Storybook は
> `@platform/ui` の**公開面（`src/index.ts`）ではなく例示**であり、
> 規約が禁じるのは**プリミティブが文言を持つこと**である。本 PR で覆さない。

### 判断 5: **`docs/specs/` と `feedback/` は触らない**

いずれも**作業当時の記録**である（`.claude/rules/traceability.md`）。
走査対象からも外してある（軸 3 のコマンドが `docs/specs` を含んでいない）。
