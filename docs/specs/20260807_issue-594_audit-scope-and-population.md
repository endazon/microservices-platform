## 目的・背景

**利用者裁定（2026-08-07・第 2 回）**が #572 の施策 3「監査の重さを risk に比例させる」を
**見直しで確定**した。本作業はその裁定を実装 ADR として明文化し、監査エージェント・コマンド・
規約・完了の定義へ反映する。

裁定の根拠は #572 のコメントに記録された実測である。要点は 3 つ。

1. PR #585 / #593 は**どちらもドキュメントのみの変更**でありながら **5 巡 / 3 巡**を要した
2. **空振りの巡は 1 度も無かった** —— 監査が無駄を出しているのではない
3. 巡が増えた主因は「**是正が新しい欠陥を入れる**」ことであり、
   **監査を一律に軽くしても機序は止まらない**（検出が減るだけになる）

したがって削るのは「巡数」、厚くするのは「実装側の母集合の引き直し」である。

## 設計

### IADR-0141 に書く決定（4 点）

裁定の 4 項目をそのまま決定にする。

| 決定 | 内容 | 向き |
| --- | --- | --- |
| **1** | 母集合の引き直しを**実装側の義務へ前倒し**し、結果と**除外理由**を作業仕様書へ書く | **厚くする** |
| **2** | 監査は**全面 1 巡を原則**とし、2 巡目以降は**是正差分のみ**。2 本の監査は**同時に**走らせる | 削る |
| **3** | 監査プロンプトに**打ち切り条件の明言**を求める | 削る |
| **4** | **risk による分岐**（4 分類） | 削る |

### 決定 1 の内訳（母集合の引き方・6 項目）

1. **誤りの側から引く**（正しい表記だけを検索語にしない）
2. **あり得る形をすべて列挙してから引く**
3. **拡張子で絞らない**（`--exclude-dir` / パスの除外だけで取る）
4. **行フィルタで絞らない。パスから引く**
5. **軸を 1 本で終わらせない**
6. **引いた結果と、除外したものとその理由を作業仕様書に書く**

### 決定 4 の分岐表

| PR の性質 | 監査 |
| --- | --- |
| 機械検査を新設・改修する | 全面 1 巡 ＋ 是正差分 1 巡（**変異試験の妥当性を必ず見る**） |
| ADR の決定に触れる／規約を改定する | 全面 1 巡 ＋ 是正差分 1 巡 |
| 記録の追随のみ | **全面 1 巡で打ち切り**。是正差分は実装側の自己検証で足りる |
| 契約追加（B 群） | 全面 1 巡 |

**本 PR 自身は「ADR の決定に触れる／規約を改定する」に当たる**ため、全面 1 巡 ＋ 差分 1 巡である。

### IADR-0139 決定 4 との関係（矛盾の解消）

**2 つの決定は直交する。** 混同しないよう ADR 本文に明記する。

| | 何を数えるか |
| --- | --- |
| **IADR-0139 決定 4** | **監査の対象の数**（束ねた PR では issue ごとに 1 回 ＋ 束ごとに 1 回） |
| **IADR-0141 決定 2** | **1 つの対象あたりの巡数**（全面 1 巡 ＋ 是正差分のみ） |

IADR-0139 決定 4 の「**#572 の施策 3 は判断なし＝現状維持**」という**前提の記述のみ**が
古くなった。**同決定の実体（対象の数）は変えない。**

## テスト方針

**本作業に自動テストは無い。** 変更対象は規約文書・エージェント定義であり、実行されるコードを
含まないためである。代わりに次の機械検査で退行を防ぐ。

| 検査 | 何を守るか |
| --- | --- |
| `node scripts/check-doc-links.js` | 追加した相対リンク（IADR 相互参照・索引）が切れていないこと |
| `node scripts/check-cross-repo-refs.js` | 他リポ参照の表記（本仕様書・ADR に `planning#NNN` を書く場合） |
| `REQUIRE_REPO_TESTS=1 node scripts/scripts.test.js` | 索引行の「形」（リンク形式・ID とファイル名の一致・閉じパイプ・タイトル長 200 字） |
| `node scripts/check-commit-messages.js` | コミット件名の `IADR-0141` が実在すること |

**索引行は 200 文字以内に収める**（`title-too-long` ラチェットの baseline を増やさないため）。
