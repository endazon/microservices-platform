# 画面仕様書: 秘密情報・接続設定の管理

> **［実装状態］`status: completed` は「本仕様書が記述する範囲の実装とテストが揃った」ことを表す。**
> 🔴 **計画の要素のうち 1 つは満たしきっていない**（未設定の判定がプロパティ単位ではなく項目単位である）。
> 理由は §計画（モックアップ・画面設計）との対応 に「一部する」として書いた。
> **モックアップは未作成である**（計画は受領を着手の条件にしていない）。見た目は共通シェルと共有 UI に従う。

## 画面概要・目的

**Git に置けない秘密情報**（API キー・接続秘密・通知の webhook）を、運用者が画面から 1 項目ずつ投入・更新する画面である。
構成（認証基盤の宣言・パイプライン・公開ツールの許可リスト）は扱わない —— それらは Git 経由を維持する。

- ルート: `/admin/secrets`
- アクセス: **運用者・システム管理者に限る**。権限外にはメニュー・画面自体を出さない（権限ガードが未検出画面を描く）。
  境界層も同じ 2 ロールに限り、未認証は 401・権限外は 403 を返す。
- 🔴 **値は書き込み専用である。** 保存後は画面からも境界層からも読み出せない（読み出しの口そのものが無い）。
- 🔴 **一括再投入の口は無い。** 1 回の操作で書くのは 1 プロパティだけである。
- 扱う項目の集合は `deploy/bootstrap/sc22-secret-items.json` の `items[]` だけ（4 項目・13 プロパティ）。
  認証基盤と対で書くべき秘密・稼働中のデータストアの資格情報は対象外である（同ファイルの `deferred[]` / `excluded[]`）。

## レイアウト / 主要素

| # | 要素 | 実装 |
| --- | --- | --- |
| 1 | 項目の一覧（項目名 / 用途 / 最終更新日時 / 最終更新者 / 操作 の 5 列） | ヘッドレスの表 ＋ 共有 UI の表構造。🔴 **値の列を置かない** |
| 2 | 状態の表示（未設定 / 取得できない / 設定済み） | 最終更新日時の欄に状態バッジ（色 ＋ アイコン ＋ テキスト） |
| 3 | 更新フォーム | 行の「更新」で開く。対象の項目名を見出しに出す |
| 4 | 状態の意味の注記 | 「設定済み」の限界と「記録なし」の意味を一覧の下に書く |
| 5 | 取得失敗 | 共通の待ち・空・失敗の描き分けに従う。**保管先に届かないときは空の一覧にしない** |

### 状態の示し方（色だけで意味を持たせない）

| 値 | 表示 | 意味 |
| --- | --- | --- |
| 設定済み | 成功（チェック）＋最終更新日時 | 保管先に値の**版**がある。🔴 **各プロパティに空でない値が入っていることは意味しない** |
| 未設定 | 警告 | 保管先に値が無い（項目ごと無い、または現在の版が削除されている）。🔴 **現在の版が削除されている項目は、この画面から更新できない**（先に版の復元が要る。下の「失敗の表示」） |
| 取得できない | 危険 | 状態を取れなかった（保管先の権限・障害）。**未設定とは区別する** |

### 最終更新者

- **この画面から更新した版が現在の版であるときだけ**、その利用者名を出す。
- コンソール（退避手段）や初期投入が書いた版は「**記録なし**」と出す。**誤った名前を出さない**ことを優先している。
- 「誰がいつ更新したか」の正本は監査ログである。

## 表示・入力項目

| 項目 | 種別 | 必須 | 初期値 | 形式・制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| 更新するプロパティ | 選択 | 必須 | 項目の最初の書けるプロパティ | 項目が持つ**書けるプロパティだけ** | 同じ項目に同居する構成値（宛先ホスト等）は選択肢に出ない |
| 新しい値 | パスワード入力（マスク） | 必須 | 空 | 1〜8192 文字 | 書き込み専用。ブラウザに保存させない |
| 新しい値（確認のためもう一度） | パスワード入力（マスク） | 必須 | 空 | 新しい値と完全一致 | 貼り付けの誤りを保存前に捕まえる（前後の空白も比べる） |
| 更新の理由 | テキスト | 任意 | 空 | 500 文字以内 | 監査ログへ残る。値そのものを書かないよう注記する |

## バリデーション

| 項目 | 条件 | エラーメッセージ |
| --- | --- | --- |
| 新しい値（確認） | 新しい値と一致しない | 確認のための入力が一致しません。（**送信ボタンは押せない**） |
| 新しい値 | 空 | （送信ボタンは押せない） |
| 新しい値 | 8192 文字を超える | 値は 8192 文字以内で入力してください。 |
| 更新の理由 | 500 文字を超える | 更新の理由は 500 文字以内で入力してください。 |
| （境界層） | 一覧に無い項目・書けないプロパティ | 境界層の検証エラーをそのまま出す（入力が不正として扱い、存在の秘匿はしない） |
| （境界層） | 送る内容が大きすぎる・解釈できない | 境界層が拒否して監査に残す。画面は上の入力規則で送る前に止めるため、通常の操作では起きない |

## アクション・イベント

| 操作 | 挙動 | 遷移先 |
| --- | --- | --- |
| 行の「更新」 | その項目の更新フォームを開く | — |
| 「このプロパティを更新する」 | 1 プロパティだけを保管先へ書く（部分更新。同じ項目の他のプロパティは消えない）。成功したら**入力を空に戻し**、書き込み後の版を示し、一覧を引き直す | — |
| 「閉じる」 | フォームを閉じる（入力は破棄される） | — |

**失敗の表示**:

| 状況 | 表示 |
| --- | --- |
| 保管先が構成されていない・接続できない（一覧） | 「秘密情報の項目を取得できませんでした。」＋ 保管先の稼働を確認する旨。**表を描かない** |
| 保管先が構成されていない・接続できない（更新） | 「……接続できません。値は保存されていません。」 |
| 保管先が書き込みを拒んだ | 「……書き込みを受け付けませんでした。値は保存されていません。」 |
| 現在の版が保管先で削除されている（一覧では「未設定」） | 「この項目の現在の版は保管先（Vault）で削除されています。……コンソールから版を復元してから、もう一度更新してください。値は保存されていません。」 |

**現在の版が削除されている項目へは、画面から書かない。** 画面の書き込み権限（部分更新と「無いときだけ作る」）では
削除された版の上へ書く手段が無く、その手段（項目の全置換）を足すと同じ項目に同居する構成値を消せてしまうためである。
運用者は[運用 Runbook](../operations/secret-item-console-injection-runbook.md) の失敗の分岐に従い、コンソールで版を復元してから画面で更新し直す。

**確認ダイアログは置かない。** 2 度目の入力がそのまま確認であり、保管先は旧版を保持するので書き直しで戻せる。
