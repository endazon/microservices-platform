# 画面仕様書: 個人資料管理

> **［実装状態］`status: completed` は「本仕様書が記述する範囲の実装とテストが揃った」ことを表す**
> （`docs/README.md` 運用ルール 6）。**本書の範囲は、公開 API に口がある機能に限る。**
> 🔴 **公開範囲（共有先）の表示と変更・同期状態の列・タグ・緊急アクセスは実装していない** ——
> いずれも呼ぶ口が存在しない。**「共有できる」「同期状態が見える」とは読まないこと。**
> 見送りの一覧と理由は §計画（画面設計）との対応 と §未決事項 にある。

## 画面概要・目的

利用者本人が、自分の個人資料を一覧し、露出（横断検索・ナレッジグラフ・AI 入力）を設定し、
削除済みの資料を復元・完全削除するための画面。**保存容量を自力で管理できることが眼目**である。

- ルート: `/my/notes`（削除済みは `/my/notes?tab=trash`。タイトルの絞り込みは `?q=`）
- アクセス: **認証済みの全利用者**（ロール限定なし）。**表示範囲は本人が所有する資料のみ**であり、
  他の利用者の資料は件数を含め一切現れない。**管理者が他人の資料を見る導線は置かない。**
- 画面ラベルは「個人資料」で統一する。「マイスペース」「個人メモ」は使わない。

## レイアウト / 主要素

| # | 要素 | 実装 |
| --- | --- | --- |
| 1 | 資料の一覧（種別 / タイトル / 更新日時 / 露出 / 操作の 5 列） | 共有 UI の表構造。行のタイトル下に同期先のパスを添える |
| 2 | 個人資料であることの表示 | 全行に **👤 ＋「個人資料（自分のみ）」**（検索結果・グラフのノードと同じ記号） |
| 3 | 業務関連資料としての扱いの固定文言 | 一覧の上部に**常時**表示（折りたたまない） |
| 4 | 保存容量 | 使用量 / 上限 ＋ 内訳「うち削除済み」＋ 版履歴が非算入である旨 |
| 5 | 段階警告 | 80%（予告）/ 95%（警告色）/ 100%（固定文言 2 段落）。**同時に 2 段は出さない** |
| 6 | 新規作成 | タイトル（必須）＋ 同期先のパス（任意）。**本文の入力欄を置かない** |
| 7 | 本文編集の代替導線 | 「本文はこの画面では編集できません」＋ 連携設定画面へのリンク |
| 8 | タブ | 利用中（件数）/ 削除済み（件数バッジ）。**URL が単一情報源** |
| 9 | 絞り込み | タイトルの部分一致（URL の `q`） |
| 10 | 削除済みの行 | 削除日時 ＋ **完全削除までの残り日数**（残り 7 日以内は警告色＋文言） |
| 11 | 一括選択と一括操作 | 復元・完全削除の**両方**。選択が 0 件のときは実行できない |
| 12 | 確認ダイアログ | 論理削除用と完全削除用の 2 種（下記） |
| 13 | 露出 3 トグル | 横断検索 / ナレッジグラフ / AI 入力。**独立**・既定はいずれもオフ |
| 14 | 空状態 | 「個人資料がまだありません」＋ 作成導線。削除済みタブでは別の文言 |
| 15 | 取得失敗 | 空状態へ縮退させず、取得できなかったことを示す |
| 16 | ヘルプ文言 | 「リンク先が表示されない理由は区別できない」旨（存在秘匿の帰結） |

### 状態の示し方（色だけで意味を持たせない）

削除済みの残り日数は共有 UI の状態バッジで示す。**色 ＋ アイコン ＋ テキスト**が型で強制される。

| 条件 | 表示 | 意味 |
| --- | --- | --- |
| 残り 8 日以上 | 中立（情報アイコン）「残り N 日」 | まだ猶予がある |
| 残り 7 日以内 | 警告（三角）「まもなく完全削除（残り N 日）」 | 通知が出る状態と一致させる |

**残り日数は切り上げる。**「あと 0.4 日」を 0 日と出すと、まだ間に合う資料が手遅れに見える。

### 確認ダイアログ

| 操作 | 出す内容 |
| --- | --- |
| 削除（論理削除） | 「削除しても容量は空きません（90 日間保管されます）」を**事前に**示す。容量を空ける手段（削除済みからの完全削除）も添える |
| 完全に削除（即時） | ①復元できない旨 ②90 日待てば自動的に完全削除される旨 ③解放される容量（選択の合計） |

🔴 **①には但し書きを添えている。** 削除が本文の実体まで及ぶ配線は未配備であり（本文の実体を消す
経路がまだ無い）、「いかなる方法でも復元できない」が事実になるのは配備後である。計画は
「文言を出さない」か「但し書きを添える」の 2 択を実装側へ委ねており、**但し書きを選んだ** ——
文言を落とすと、取り返しのつかない操作の手前で最も重要な警告が消えるためである。
**現在の状態を伏せず**、「削除の反映には時間がかかる場合があります」を同じ段落に置く。

## 表示・入力項目

| 項目 | 種別 | 必須 | 初期値 | 形式・制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| タイトル | テキスト | 必須 | 空 | 空白のみは不可 | 空のままでは作成ボタンを押せない |
| 同期先のパス | テキスト | 任意 | 空 | 省略時はサーバがタイトルから決める | 省略時は要求に `null` を送る |
| タブ | 選択 | 任意 | 利用中 | 利用中 / 削除済み | URL の `tab`。未知の値は既定へ倒す |
| タイトルの絞り込み | テキスト | 任意 | 空 | 部分一致（大小文字を無視） | URL の `q` |
| 露出 3 トグル | チェック ×3 | 任意 | すべてオフ | 独立 | 変えていない 2 つは現在値のまま送る |
| 削除済みの選択 | チェック | 任意 | 未選択 | 複数可 | タブを切り替えると選択は捨てる |
| 本文 | — | — | — | — | 🔴 **入力欄を置かない。** 本文は連携設定の経路でのみ書ける |

## バリデーション

| 項目 | 条件 | エラーメッセージ |
| --- | --- | --- |
| タイトル | 空白のみは作成できない | （出さない。ボタンを無効化する） |
| 新規作成 | **使用量が上限の 100% では実行できない** | 「保存容量の上限に達しました。…」（固定文言 2 段落） |
| タブ | 未知の値は既定へ倒す | （出さない。選択肢しか無い UI にエラー状態を持ち込まない） |
| 一覧の取得 | 失敗したら**空の一覧へ縮退しない** | 「個人資料の一覧を取得できませんでした。時間をおいて再度お試しください。」 |
| 書き込みの失敗 | 直近の操作の結果だけを出す | サーバの詳細（あれば）／無ければ「操作に失敗しました。…」 |

値域の防壁はサーバ側にある。画面は丸めるだけである。

## アクション・イベント

| 操作 | 挙動 | 遷移先 |
| --- | --- | --- |
| 作成する | タイトル（＋パス）だけを送る。成功で入力を空にする | 同じ画面 |
| 露出トグル | 3 値を揃えて送る（変えた 1 つだけが変わる） | 同じ画面 |
| 削除する | 確認ダイアログ → 論理削除 | 同じ画面 |
| 復元する | 単票・一括のいずれも即時に実行する（破壊的でないため確認を挟まない） | 同じ画面 |
| 完全に削除する | 確認ダイアログ → 単票／一括を**同じ口**へ送る | 同じ画面 |
| タブ・絞り込みの変更 | URL を書き換える | 同じ画面 |
| 連携設定へ | 本文を書く経路の案内から遷移する | 連携設定画面 |

**置かない操作**: 本文の編集・公開範囲の変更・管理者による一括閲覧／一括変更・上限の引き上げ。
不在は単体テストが陽性対照つきで固定する。

## 権限・表示条件

- ロール限定なし（「個人」グループの画面）。左ナビに「個人資料」として出す。
- **表示範囲は主体（セッション）で決まる。** 画面は所有者を指定する口を持たず、
  要求にも所有者を運ぶ項目を載せない。他人の資料は件数にも現れない。

## 計画（画面設計）との対応

| 計画側の要素 | 実装 | 満たしていない条件 / 理由 |
| --- | --- | --- |
| 一覧（タイトル / 更新日 / 公開範囲 / 同期状態 / タグ） | **一部する** | タイトル・更新日は出す。🔴 **公開範囲・同期状態・タグの 3 列は出せない** —— 一覧が返す台帳に該当する項目が無く、引く口も無い。**繰り延べであって放棄ではない**（§未決事項 1） |
| 公開範囲の 3 状態の表示・変更ダイアログ | **しない** | 🔴 **共有先を読む口も書く口も公開 API に無い。** 契約を足すのは別の変更単位であり、先に画面だけ描くと「操作できるように見えて何も起きない」UI になる |
| 新規作成の導線（リッチエディタを描かない・本文編集の導線も持たない） | する | 入力はタイトルとパスだけ。本文の欄も編集導線も無いことを単体テストが固定 |
| 同期状態の表示（同期対象 / 対象外 / 競合あり） | **しない** | 上と同じ（台帳に該当項目が無い）。競合の一覧は連携設定画面の関心でもあり、そちらも未実装 |
| 検索・絞り込み（タイトル / タグ / 公開範囲 / 同期状態） | **一部する** | タイトルのみ。他の 3 軸は列そのものが無いため絞れない |
| 空状態 | する | 利用中・削除済みで文言を分ける |
| 緊急アクセス（Break-glass）の導線 | **しない** | 🔴 **発動を記録する口が公開 API に無い。** 理由入力・監査ログの明示・15 分の自動失効はサーバ側の発動記録が前提であり、画面だけでは統制にならない |
| 「削除済み」タブ（削除日時・残り日数） | する | 同じ応答を絞って描く（問い合わせを分けない） |
| 復元 | する | 単票・一括の両方 |
| 完全に削除（即時）＋確認ダイアログ | する | ①②③ を出す。①には但し書き（前掲） |
| 一括選択と一括操作（復元・完全削除の両方） | する | 一括完全削除は**単票と同じ口**へ送る（要素数の差でしかない） |
| 完全削除が近い項目の強調（残り 7 日以内は警告色） | する | 色に加えて文言も変える（境界の両側を単体テストが固定） |
| 削除済みの件数バッジ | する | 一覧の件数と同じ数え方（同じ応答から数える） |
| 容量表示（使用量・上限・うち削除済み・80/95 の段階警告） | する | 内訳は削除済み行の合算（契約が「数え方を 2 つにしない」と定めている） |
| 100% で新規作成のみ拒否・固定文言 | する | 既存資料の操作は残ることも単体テストが固定 |
| 業務関連資料としての扱いの固定文言（隠さない） | する | 折りたたみの中に入れていないことを単体テストが固定 |
| ヘルプ文言（リンク先が見えない理由は区別できない） | する | 常時表示 |
| リンク作成 UI（補完候補の絞り込み・404 原則） | **しない** | 🔴 **リンクを作る口が公開 API に無い。** ヘルプ文言だけは先に置いてある |
| 他人の資料の件数・存在を示唆しない | する | 示唆表現の不在を陽性対照つきで固定 |
| 管理者による一括閲覧・一括変更を描かない | する | 同上 |
| 本画面内での本文編集を描かない | する | 同上 |

## 未決事項

1. 🔴 **公開範囲（共有先）の表示・変更が無い。** 計画の主要素 2・3 と入力表の第 1 行を満たしていない。
   読む口も書く口も公開 API に無く、契約の追加は別の変更単位である。
2. 🔴 **同期状態の列とタグ列が無い**（主要素 1・5・6 の一部）。台帳に項目が無い。
3. 🔴 **緊急アクセス（Break-glass）の導線が無い。** 発動記録の口が無く、画面だけでは
   「15 分で自動失効し、有効性はサーバ側の発動記録で判定する」という統制を満たせない。
4. **完全削除の確認文言に但し書きを添えている**（前掲）。実体削除の配線が入ったら但し書きを外す。
5. 計画が未確定としている論点（文書管理画面との責務分界、AI 入力の資料単位設定の設置場所、
   「非公開」の表示語）はそのまま残っている。**資料単位の露出は本画面に置いた** ——
   利用者単位の既定を置く口が無く、資料単位の口だけが在るためである。
