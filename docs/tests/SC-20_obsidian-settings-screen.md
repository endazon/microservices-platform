# テスト仕様書: Obsidian 連携設定画面

## テスト対象・範囲

> **`status: completed` の意味**: **画面（フロントエンド）が実装され、本書の観点が実測で緑になった**。
> 従前の「先取りの台帳」は下の表へ実測として置き換わっている。
>
> 🔴 **Obsidian プラグイン本体は依然として未実装である。** 本画面は端末とトークンを管理するだけで、
> **同期そのものは動かない。** 同期対象フォルダの設定・競合の解決・同期履歴・一時停止は
> **呼ぶ口が公開 API に無いため実装していない**。差分は画面仕様書の対応表が持つ。

- 同期プロトコルそのもの（マニフェスト・push・pull・削除の伝播）の写像は
  [FR-20_obsidian-sync](FR-20_obsidian-sync.md) が正である。本書は**設定画面が触る面**を扱う。
- 同期トークンは**ブラウザセッションとは別系統の資格情報**であり、画面はトークンで API を呼ばない。

## 実体

| 層 | テストクラス／ファイル | 主に固定していること |
| --- | --- | --- |
| BFF（認可） | `BffPrivateNoteEndpointTests` | 無認証は 401 ／ 他人の端末は 404（403 にしない）／ 平文トークンは発行応答にだけ現れる ／ 失効は文書ポリシーの有無に依存しない |
| 文書サービス | `SyncDeviceTokenTests` | 有効期限 30 日・手動再発行のみ ／ 個別失効・一括失効 ／ 他人の端末に到達できない |
| 画面 | `sc20-obsidian-settings/components/ObsidianSettingsPage.test.tsx` | 固定文言 3 段落・4 状態の描き分け・平文の一度きり表示・確認ダイアログ・否定形 |
| 純関数 | `sc20-obsidian-settings/types/deviceState.test.ts` | 4 状態の境界（残り 7 日と 8 日）・失効の最優先判定 |

## 観点

- 🔴 否定形（他人の端末に到達できない・平文が一覧に出ない・承認ステップが無い・自動更新が無い）は
  **陽性対照と対で**置く ——「常に 404」「常に空」の実装でも陰性だけなら緑になる。
- **失効は通す側で固定する。** 個別失効は端末紛失時の唯一の防御線であり、
  文書側のポリシー整備状況に依存して塞がってはならない。**画面側でも状態を理由に隠さない。**
- **自動更新（リフレッシュ）の口が存在しないこと**は、API の一覧に現れないことと、
  画面に導線が無いことの両方で担保する。
- 🔴 **時刻は固定する**（残り日数・期限切れの境界が「いま」に依存するため）。

## テストケース一覧（計画の受け入れ基準からの写像）

| # | 受け入れ基準 | 実測 |
| --- | --- | --- |
| 1 | 端末一覧が「有効（残り日数）／期限切れ間近（残り 7 日以内）／期限切れ／失効」を区別して表示する | 緑（4 値すべてを同時に描く一覧で固定） |
| 2 | トークンは発行直後に一度だけ表示し、再表示できない（再発行の導線を同じ行に置く） | 緑（発行前に平文が無いことを陰性の前提に置く） |
| 3 | 期限切れ後もプラグイン設定には旧トークンが残る旨の固定文言が表示される | 緑 |
| 4 | 一括失効の確認ダイアログに復元不可である旨が表示される | 緑（対象台数も提示。押すまで要求が飛ばないことも固定） |
| 5 | 同期対象フォルダの指定 UI の隣に、業務関連資料としての扱いの固定文言がある | 🔴 **一部**（文言は出すが、**フォルダ指定 UI が無いため隣に置けていない**。画面仕様書 §未決事項 1） |
| 6 | 露出 3 トグルが独立に設定でき、既定はいずれも OFF である | 🔴 **本画面では未達**（資料単位の設定は個人資料管理画面のテストが固定。利用者単位の既定は口が無い） |
| 7 | 失効済み以外の全行に個別失効がある（期限切れの行にも残る） | 緑（失効済みの行に無いことと対で固定） |
| 8 | 期限切れの行から同じ行で再発行できる | 緑 |
| 9 | 再発行がその端末の口を叩き、平文を一度だけ出す | 緑 |
| 10 | 次の操作を始めると平文の表示が消える（画面に残さない） | 緑 |
| 11 | 自動更新（リフレッシュ）の導線が無い | 緑（手動再発行の存在を陽性対照に置く） |
| 12 | 端末登録に管理者承認のステップが無い | 緑（発行ボタンが押せることを陽性対照に置く） |
| 13 | 組織文書・他利用者の設定への導線が無い | 緑（自分の個人資料への導線を陽性対照に置く） |
| 14 | 固定文言 3 段落が出る（削除の説明に「90 日を過ぎると復元できない」を含む） | 緑 |
| 15 | 業務関連資料の説明を削除の説明と同じ段落にまとめない | 緑（同じ段落に 90 日の文が無いことを固定） |
| 16 | 端末が 0 台のときは空状態を出し、一括失効を押せない | 緑（発行の導線は残ることを対で固定） |
| 17 | 一覧を引けないときは空状態へ縮退しない | 緑 |
