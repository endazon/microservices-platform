# テスト仕様書: ナレッジグラフビュー

## テスト対象・範囲

ナレッジグラフビュー（`/graph`）の画面と、その画面が要求した口（近傍探索の辺の型フィルタ・
ノードの個人資料フラグ）。多ホップ探索・二段上限・総数・間引き基準そのものは既存のテスト
（探索側のテスト群）が固定しており、本仕様書の範囲外。

## テスト観点

- 描き分けの写像（形・アイコン・線種・矢印。**色だけに頼らない**）
- 探索条件（hops / 間引き基準 / 型フィルタ）が URL とサーバ照会の両方へ効くこと
- 空状態 2 種＋起点未指定の描き分けと、ヘルプ固定文言の常時表示
- 型フィルタが**サーバ側**（探索の入口）で効くこと。否定形（絞ると消える）は陽性対照
  （絞らなければ現れる）と対で置く
- 存在秘匿（400/404 の打ち分けから文書の存在が漏れないこと）

## テストデータ

- 探索側（xUnit）は InMemory ストアへ星型・分岐型のグラフを seed する（可視 / 不可視・型 2 種・
  文書スコープ属性の有無を混在させる）。
- 画面側（Vitest）は BFF 応答（近傍探索・型辞書・文書詳細）をモックし、3 ノード 2 辺の固定
  ビューと打ち切りバリエーションを使う。
