# テスト仕様書: 個人資料管理画面

## テスト対象・範囲

> **`status: completed` の意味**: **画面（フロントエンド）が実装され、本書の観点が実測で緑になった**。
> 従前の「先取りの台帳」は下の表へ実測として置き換わっている。
>
> 🔴 **画面が持っていない機能は本書の対象外である。** 公開範囲（共有先）・同期状態の列・タグ・
> 緊急アクセス・リンク作成は**呼ぶ口が公開 API に無いため実装していない**。
> 「テストが緑＝計画の全要素が満たされた」ではない —— 差分は画面仕様書の対応表が持つ。

- バックエンド API の写像は [FR-19_private-notes-lifecycle](FR-19_private-notes-lifecycle.md) が正。
- 認可（無認証 401・他人の資料は 404・書き込みの拒否）は BFF 側のテストが固定しており、
  画面側では再現しない（判定軸を 2 本持たない）。

## 実体

| 層 | テストの所在 | 主に固定していること |
| --- | --- | --- |
| 画面 | `sc19-private-notes/components/PrivateNotesPage.test.tsx` | 固定文言・容量の段階・確認ダイアログ・一括操作・露出トグル・否定形 |
| 純関数 | `sc19-private-notes/types/quota.test.ts` | 段階警告の境界（両側）・内訳の合算・残り日数の切り上げ |
| 共有部品 | `components/ConfirmDialog.test.tsx` | 押すまで実行されないこと・初期フォーカス・Escape |

## 観点

- 🔴 否定形（本文編集欄が無い・管理者導線が無い・他人の資料の件数が出ない）は**陽性対照と対で**置く。
  何も描かない実装でも否定形だけなら緑になる。
- 🔴 **時刻は固定する**（残り日数と警告色の境界が「いま」に依存するため）。実時間のままだと
  日付をまたいだ瞬間に赤くなるテストになる。
- 境界（80 / 95 / 100 の使用率、残り 7 日と 8 日）は**両側**を置く。

## テストケース一覧（計画の受け入れ基準からの写像）

| # | 受け入れ基準 | 実測 |
| --- | --- | --- |
| 1 | 論理削除の確認時に「削除しても容量は空かない（90 日保管）」が表示される | 緑（対象名の提示・押すまで要求が飛ばないことも同時に固定） |
| 2 | 完全削除の確認時に ①復元不可 ②90 日待てば自動 ③解放される容量 が表示される | 緑（①には実体削除が未配備であることの但し書きを含む） |
| 3 | 削除済み一覧から単票・複数選択の一括完全削除の双方が実行できる | 緑（一括は単票と同じ口へ送ることも固定） |
| 4 | ラベルは「個人資料」で統一し、アイコン＋ラベル併用（色だけで意味を持たせない） | 緑（「マイスペース」「個人メモ」の不在を陽性対照と対で固定） |
| 5 | 一括完全削除の選択内容が実行直前に再提示される | 緑（対象件数と解放容量の合計を提示） |
| 6 | 業務関連資料としての扱いの固定文言が常時表示され、折りたたまれない | 緑 |
| 7 | 容量が使用量・上限・「うち削除済み」の内訳とともに出る | 緑（内訳は削除済み行の合算） |
| 8 | 80 / 95 / 100 で警告が段階的に変わり、同時に 2 段は出ない | 緑（4 段すべてと「95% で 80% を出さない」を固定） |

| 13 | 残り 7 日以内だけが警告色＋文言になる | 緑（3 日と 60 日の両側） |
| 14 | 復元が単票・一括の双方でできる | 緑 |

| 16 | 空状態（作成導線つき）を描く | 緑 |
| 17 | タイトルで絞り込め、条件が URL に載る | 緑 |
| 18 | 未知のタブ名を既定へ倒す | 緑 |
| 19 | 一覧を引けないときは空状態へ縮退しない | 緑 |
| 20 | 管理者導線・他人の資料を示唆する表示が無い | 緑（自分の資料が見えることを陽性対照に置く） |
