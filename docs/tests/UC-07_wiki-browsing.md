# テスト仕様書: Wiki で閲覧する

## 本書の位置づけ

**既にあるテストと計画の受け入れ基準を突き合わせた記録である。** 本書を起こした作業はテストを
1 件も足していない。突き合わせで見つかった穴のうち、テストを書けば埋まるものは別 issue へ切った。

**［2026-09-02 追記］** その別 issue で **「検索する」と「未認証時の応答」の 2 件が埋まった。**
「未実施」節から当該 2 項目を削り、下のテストケース表へ **T-28〜T-40** として移した。
検索は Wiki 本体へ委譲した結果を前段の権限判定で絞り直す形で入っており、**委譲先が返した結果を
そのまま見せることはしない**。未認証時の応答は「一覧・検索は 200 と空、個別は 404」に固定した。

## 計画の逐語（本書が写像する対象）

- 事前条件: **認証済み**。対象文書の閲覧権限がある。
- 事後条件: **権限内の文書のみが閲覧できる**。
- 基本フロー: (1) 利用者が Wiki で文書を**開く／検索する** → (2) **ABAC で閲覧可否を判定し、
  権限内の文書を表示する**。
- 例外フロー: **権限外の文書は一覧・本文のいずれにも表示しない**。

## フローの写像

| フロー | 手順 | 検査すること |
| --- | --- | --- |
| 基本 1 | 文書を開く | 一覧・スラッグ・文書 ID の 3 経路すべてで判定が効く |
| 基本 1 | 検索する | 委譲先の当たりを台帳と突き合わせ、権限判定を通ったものだけを関連度順で返す |
| 事前条件 | 認証済み | 未認証の応答が固定されている。**権限の問い合わせ先を叩く前に落ちる** |
| 基本 2 | ABAC で可否を判定する | deny-by-default。分岐は論理和、分岐内の条件は論理積。属性キーを欠く文書は見せない |
| 例外 | 権限外 | 一覧に出さず、個別取得は **404**（403 でない）。アーカイブ済みも 404 |
| 事後条件 | 同期の側 | 個人資料は Wiki へ**押し出さない**。認可属性は Wiki 側へ持ち込まない。削除・アーカイブは伝播する |

### T-39 に「呼ばれていないこと」を組み込む理由

**「拒否された」と「そもそも聞きに行かなかった」は違う。** 従前の実装は未認証でも匿名の身元で
権限を問い合わせており、**利用者条件を持たない許可が 1 件でも入れば匿名にも権限が下りる**状態だった
（拒否は結果論であって契約ではなかった）。T-39 は問い合わせ先を**最も甘い構え（全許可）**に置いた
うえで、空／404 になることと**問い合わせ回数が 0 であること**の両方を測る。
T-40 はその対で、**同じ構えのまま認証済みなら通る**ことを示す —— これが無いと
「常に拒否する実装」が T-39 を通してしまう。

### T-02・T-04・T-08 に陽性対照を組み込む理由

存在秘匿の検査は否定形（404・空一覧）ばかりになる。**判定器が常に落とす実装**でも全部緑になるため、
見えるべきものが見えることを同じテスト群の中に置く。

## 未実施（しない／一部する）

- **Wiki.js 本体の表示・編集はしない。** 閲覧・編集の実体は Wiki.js に委譲しており、本書が測るのは
  前段の認可ゲートウェイである。
- 🔴 **委譲先が自前で持っている検索画面は、前段を通らないままである。** 画面から委譲先へ直接
  遷移した先の検索がそれに当たる。**本書の T-28〜T-38 が測るのは前段の経路だけ**であり、
  向こう側の検索は**測っていないし塞いでもいない**。**「検索は全部 ABAC を通っている」と読まないこと。**
  塞ぐには画面側の実現方式（ページツリー・本文をどちら側で描くか）の裁定が要り、本書の範囲ではない。
- **前段の経路を画面用の口へ出していない。** 4 経路はいずれもサービス直の契約であり、
  画面用の口には現れない。画面側の裁定が済むまで露出しない（露出面を経路ごとにばらけさせない）。
- **稼働 Wiki.js を通した検査はしない。** クライアントは記録スタブで測る。GraphQL のスキーマ整合は
  実測した応答形を固定する形で覆う。
- **既知の観測（仕様ではない）**: 組織文書として同期済みの文書が後から個人資料へ変わっても、
  作成済みのページとメタデータは残る。計画が「既にあるページを消す」ことを定めていないため、
  テストは**現状の観測**として固定してある。文書スコープ自体は不変であり、この経路は通常起きない。
