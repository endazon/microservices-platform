# 手順ガイド: Obsidian プラグインの実機目視

> **仕様ではなく作業手順の案内である**（`docs/README.md`）。導入の手順は
> [入手・導入・配布の手順ガイド](obsidian-plugin-install.md) にある。本書はその後に行う**目視の順番と、
> 何が見えれば合格か**だけを持つ。
>
> **Obsidian デスクトップ版のある端末で、人が行う。** 検証環境にも CI にも Obsidian 本体は無い。

## 何を機械で既に測っていて、何を人が見るのか

目視の範囲を広げすぎないために、先に**機械で測れている面**を書く（2026-09-26 に実測）。

| 面 | 何が保証しているか | 目視は要るか |
| --- | --- | --- |
| 同期プロトコル（衝突解決・版・push / pull の計画と実行・パスの正規化・ハッシュ） | 単体テスト（`src/obsidian-plugin/src/protocol/*.test.ts`） | 要らない |
| 実 HTTP での往復 | CLI ハーネス（`dist/cli.mjs`）の実走 | 要らない |
| **Obsidian の API 名と引数の形**（`vault.on('modify' / 'delete' / 'rename')`・`requestUrl` の引数・`saveLocalStorage`・`addCommand` など） | **型検査**。プラグインは公式の型定義（`obsidian` パッケージ）に対して `tsc --noEmit` され、フロントの CI が走らせる | **要らない**（下の変異で確かめた） |
| イベントが**いつ**届くか・通知の文言が**見えるか**・ダイアログが**描かれ、押せるか**・トークンが**どこへ**保存されるか | 何も保証していない | **要る（本書の範囲）** |

型検査の検出力は変異で確かめた（公式の型定義 1.13 系に対し、1 か所ずつ壊して戻した）:

| 変異 | 結果 |
| --- | --- |
| `vault.on('modify', …)` を `'modifyy'` にする | `TS2769 No overload matches this call` で赤 |
| `'rename'` の callback の第 1 引数を `number` にする | `TS2769`（`TAbstractFile` を要求）で赤 |
| `requestUrl({ throw: false })` を `throws` にする | `TS2561 'throws' does not exist in type 'RequestUrlParam'` で赤 |
| `saveLocalStorage` を 1 文字削る | `TS2345 'App' is not assignable to 'LocalStorageLike'` で赤 |
| 元に戻す | 0 件（緑） |

**つまり「API 名や引数を間違えていても緑になる」は成り立たない。** 残るのは**実行時の振る舞い**だけであり、次の 5 項目がそれに当たる。

## 準備

1. 導入手順ガイドのとおりにプラグインを Vault へ入れ、有効にする。
2. 接続先 URL と同期フォルダ（既定 `個人資料`）を設定タブで入れる。
3. Obsidian 連携設定画面で**検証用の端末**を 1 つ発行し、トークンを設定タブへ貼って保存する。
   **本物の業務資料が入っていない検証用の利用者で行う**（項目 4・5 で失効・無効化を行うため）。
4. 画面録画を始める（OS 標準の録画でよい）。**証跡は録画か、手順番号つきのスクリーンショットに限る。**
   「確認した」という宣言だけでは合格にしない。

## 目視の項目

各項目の「見えるべきもの」がすべて見えたら合格。1 つでも違えば、その時点の画面と
開発者ツールのコンソール（`Ctrl+Shift+I`）を録画に残して止める。

### 1. Vault のイベント（保存・削除・リネーム）が拾われ、次の同期で反映される

| 手順 | 見えるべきもの |
| --- | --- |
| 1-1 同期フォルダ内に `目視-1.md` を作り、本文を書いて保存する | ― |
| 1-2 コマンドパレットで「個人資料を同期する（取り込み → 送信）」を実行 | 通知に送信 1 件（新規）が出る。個人資料管理画面に同名の資料が現れる |
| 1-3 本文を変えて保存 → **30 秒以上空けて**もう一度変えて保存 → 同期 |個人資料管理画面の版履歴で**版が 2 つ**進む。続けて 30 秒以内に 2 回保存 → 同期すると、**版は 1 つ**だけ進む（静穏窓の畳み込み） |
| 1-4 `目視-1.md` を同期フォルダ内で `目視-1b.md` にリネーム → 同期 |個人資料管理画面で**同じ資料の名前が変わる**（別資料として増えない） |
| 1-5 同期フォルダの**外**へ移動 → 同期 |個人資料管理画面の資料は**そのまま残る**（フォルダ外への移動は同期を止めるだけで、削除は送らない）。以後その資料をフォルダ外で編集しても送られない |
| 1-6 別の資料を同期フォルダ内で削除 → 同期 |個人資料管理画面で論理削除される（ゴミ箱から復元できる） |
| 1-7 同期フォルダ**外**の `.md` を保存・削除 | 何も送られない（通知の件数に現れない） |

### 2. 競合ダイアログ（3 択＋保留）

| 手順 | 見えるべきもの |
| --- | --- |
| 2-1 同じ資料を個人資料管理画面（ブラウザ）で編集して保存し、Obsidian 側でも同じ資料を編集して保存 → 同期 | ダイアログ「個人資料の競合」。版の進み（`版 N → M`）と未送信の編集の件数が出る。ボタンは「ローカルを採用」「サーバを採用」「両方残す」「保留（次回の同期でまた確認）」 |
| 2-2 **何も押さずに**ダイアログを閉じる | どちらの内容も上書きされていない（保留扱い）。次の同期で同じダイアログが再び出る |
| 2-3 「ローカルを採用」 |個人資料管理画面の内容が Obsidian 側の内容になる |
| 2-4（2-1 を作り直して）「サーバを採用」 | Obsidian 側のファイルが個人資料管理画面の内容で上書きされる |
| 2-5（2-1 を作り直して）「両方残す」 | Obsidian 側はサーバの内容になり、Obsidian 側の内容は**別名の新しい資料**として個人資料管理画面に現れる |

### 3. 設定タブ（トークンを再表示しない・`data.json` に入らない）

| 手順 | 見えるべきもの |
| --- | --- |
| 3-1 設定タブを閉じて開き直す | 同期トークン欄は「保存済み（この端末のみ）」と出るだけで、**値は表示されない** |
| 3-2 Vault の `.obsidian/plugins/msp-private-notes-sync/data.json` をテキストエディタで開く | 接続先・同期フォルダ・同期状態・未送信の編集はあるが、**トークンの値もキーも無い** |
| 3-3 開発者ツールのコンソールで `!!app.loadLocalStorage('msp-private-notes-sync/sync-token')` を実行 | `true`（端末ローカルの保管場所に在る）。🔴 **値そのものを表示するコードは実行しない**（録画に残る） |
| 3-4 設定タブで「削除」→ 3-3 を再実行 | `false` |

### 4. 失効・期限切れのトークンで止まる

| 手順 | 見えるべきもの |
| --- | --- |
| 4-1 Obsidian 連携設定画面で検証用端末を失効させる → Obsidian で同期 | 通知「同期できませんでした: 同期トークンが無効です（期限切れ・失効・未登録）。…」 |
| 4-2 失効の前後で Vault のファイルと `data.json` の同期状態を比べる | 変化が無い（失効のせいで消えたり書き換わったりしない） |

期限切れ（30 日）は待てないので、失効で代える（サーバの応答はどちらも同じ 401 であり、プラグインは区別しない）。

### 5. アカウントを無効化したときに同期トークンが止まるか

［2026-09-26 更新］**直した。** 文書サービスが同期要求ごとに所有者のアカウントが有効かを利用者名簿で確かめ、
無効化・判定不能なら 401 を返す（自動試験で固定済み。trace ブロック参照）。ここで確かめるのは、**稼働クラスタで
名簿の口が実際に配線されていること**と、プラグインの表示である。

| 手順 | 見えるべきもの |
| --- | --- |
| 5-1 新しい端末を発行して同期が通ることを確かめる（陽性対照） | 同期が成功する。🔴 **ここで「同期トークンが無効です」になるなら、名簿の口が配線されていない**（文書サービスは名簿を引けないと通さない） |
| 5-2 ユーザーアカウント管理画面で検証用の利用者を無効化する → Obsidian で同期 | 項目 4 と同じ「同期トークンが無効です」（**無効化の直後の 1 回目から**） |
| 5-3 ユーザーアカウント管理画面で利用者を有効化し直す → Obsidian で同期 | **同期が再び成功する**（無効化はトークンを失効させていないため。期限内で失効させていない端末に限る） |
