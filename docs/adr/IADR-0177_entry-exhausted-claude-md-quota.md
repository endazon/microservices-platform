## ★★ 決定 1: **入口は尽きた。総括を行う**

**入口全体を塊単位で走査し、出せる塊をすべて出した。残る候補は 0 である**（走査結果は作業仕様書 §軸 a）。

**[[IADR-0175]] 決定 2 は「段 4 の後に総括」、[[IADR-0176]] 決定 3 は「段 5 の後へずらす」と定めた。**
**ここで実行する。**

**入口に残っているのは規範だけ**である —— 現行 pin でのレンジ ／ `NFR` の採番 ／ `Proposed` でも ID
としては実在すること ／ 着手条件は FR 単位で読むこと ／ CI は計画 ADR の実在性を守っていないこと ／
ID 修飾の書式 ／ 残す箇所と書式 ／ **母集合の取り方の規則 1〜8 とその破れた実例** ／ 守ること。

## ★★ 決定 2: **塊単位の走査を「全節」へ広げる**（[[IADR-0176]] 決定 2 の拡張）

**[[IADR-0176]] 決定 2 は「**残す**と分類した節も塊単位で測り直す」と定めた。狭い。**

**実測では「出したと分類した節」にも残っていた** —— 段 1 で処理した `## コミットメッセージの機械チェック`
から、本段でさらに 2 塊が出た（作業仕様書 §軸 a）。

| | |
| --- | --- |
| [[IADR-0176]] 決定 2 | **「残す」**と分類した節を測り直す |
| **本決定** | **分類の別を問わず、全節を塊単位で測る**。**「処理済み」も安全ではない** |

> **★ 「一度通った」は「もう無い」ではない。** 節を通したときの判断は、
> **そのとき出そうとしていた塊の周辺しか見ていない。**

## ★★ 決定 3: **`CLAUDE.md` から出す量を確定し、着手を解禁する**

**[[IADR-0175]] 決定 2 の「それまで `CLAUDE.md` に手を付けない」を解除する。**
**必要量が確定したためである**（実測値は作業仕様書 §総括）。

**次の子 issue で `CLAUDE.md` を塊単位で走査し、減量する。**

> **★ 下限であって必要量ではない。** `CLAUDE.md` 側の規範比率は**未実測**である。
> **段 3 は 28%、段 4 は 26.4% しか出せなかった** —— 同程度なら、**必要量に届かない可能性がある。**

## 決定 4: **届かない場合も [[IADR-0173]] の 2 決定は曲げない**（[[IADR-0175]] 決定 3 の再確認）

**`CLAUDE.md` を尽くしても 50,000 に届かないなら、届かないままとする。**

| 曲げない決定 | 理由 |
| --- | --- |
| 規範は別紙へ出さない | **別紙を読まなかっただけで成果物が壊れる** |
| 見出しはスタブとして残す | **確定済み記録が節名で引いている**（本段の対象節は**確定済み 20 件で最多**） |
| 事故の実例は削らない | **実例は規則の中身そのもの**。減量のために事故の記録を省かない |

> **★ 50KB は手段の目安であって、規約を守らせる力より優先しない。**
> **到達しなかったこと自体は、実測値とともに記録すれば足りる。**

## ★★ 決定 5: **切り出しの境界は「行頭」に揃える**（同型 2 回目なので検査器を置く）

**段 3 は行番号で切って文の途中を分断した。段 5 は文字列で切ったが、`  `（行頭のインデント）を残した**
——`- **ADR / IADR の実在性**` が前の箇条の**子項目として描画される**状態になった（本 PR のレビューが検出）。

**同じ型である** —— **切り出しの境界が行頭に揃っていない。**
**「文の途中で切らない」だけでは足りず、「行の途中で切らない」まで要る。**

| | |
| --- | --- |
| 規範 | **切り出しの開始・終了はいずれも行頭（列 0）に揃える。** 行の途中から切り始めない |
| 機械検査 | **空白のみの行・行末空白・空行の 2 行以上の連続**を入口と別紙で検査する（`scripts.repo.test.js`） |

> **★ 残骸の型は 1 つではない。是正そのものが次の残骸を作りうる。**
> 上記の是正（空白のみの行 → 空文字列の行）が、**直後の既存の空行と合わせて連続空行**を生んだ
> （2 巡目のレビューが検出）。**初版の検査は空文字列の行に当たらないので捕まらなかった。**
> **検査を足すときは「今直した型」だけでなく「その直し方が作る型」まで見る。**

**`CLAUDE.md`「検査器・規約の追加は同型の事故が 2 回起きたら」に従う**（1 回目は段 3 で記録に留めた）。

> **★ 機械検査が捕まえるのは残骸だけである。** **インデントがずれたこと自体は捕まらない**
> —— 正しいインデントは文脈依存で、機械には決められない。**そこは書く側が守る。**
> **本 PR では、develop と HEAD の全箇条について先頭空白を突き合わせて全数確認した**（作業仕様書 §判断 5）。
