# IADR-0169: 他リポジトリ参照の検査対象を `.md` 外へ広げる（#583）

- 状態: Accepted
- 日付: 2026-08-11
- 決定者: claude（実装）

## 起点・関連

- **NFR**（文書統制）。実装 issue: **#583**（出所は #507 のマージ前クロス監査）
- 作業仕様書: [20260810_issue-583](../specs/20260810_issue-583_cross-repo-spaced-refs.md)
- **[IADR-0140](./IADR-0140_cross-repo-issue-ref-checker.md) 決定 4 を覆す**（後述）

## 文脈 —— **#583 の主張はほぼ解消済みで、残った 1 件が本丸だった**

#583 は 2026-08-07 の起票である。**起票文の実測をそのまま作業量として受け取ると、
存在しない 95 occurrence / 48 ファイルを探すことになる。**
develop `39d6973` で全数を引き直した結果は次のとおりである。

| #583 の主張 | 実測（develop `39d6973`。2026-08-11 時点） |
| --- | --- |
| 検査器は 2 パターンで本形を検出できない | **誤り。型 3（`spaced`）は実装済み**で、型 4（owner 誤り）を含め **4 型**ある |
| 是正対象 95 occurrence / 48 ファイル | **`.md` は是正済み。** 検査器は追跡 `.md` **619 件で違反 0** |
| `.claude/rules/traceability.md` が自身の違反 | **是正済み。** 残るのは規約自身が書く「誤: 」の例（インラインコード内） |
| `deploy/local/observability/*.yaml` に `AST #24` | **是正済み。** 現在はすべて詰めた形 |
| `.md` 以外にも散っている | **正しい。ただし本物は 1 件だけ**（後述） |

### **素の正規表現の当たり数を違反数と読まない**

**検査器の判定式そのものを使い、`--markdown` の除外（インラインコード／フェンス）だけを外して数えた**
（別の正規表現を手で書くと、当たり数の差が「式の違い」なのか「除外の有無」なのか分からなくなる）。
追跡 `.md` **619 件**で **72 occurrence / 12 ファイル**が当たり、**除外を戻すと 0 件**になる。
**全数がインラインコード／コードフェンスの中**であり、**規約の「誤: `AST #24`」と、是正記録が引用する誤り文字列そのもの**である。
検査器は `--markdown` 時にこれを意図的に除外している（IADR-0140）。

> **★ #583 の起票文が「95 occurrence」と書いたのも同じ数え方**であり、
> **そのうち何件が引用だったかは書かれていない。**
> `.claude/rules/traceability.md` 規則 4「行フィルタで絞らない」の**裏返し**である ——
> **絞らずに引いた生の当たり数を、そのまま欠陥数として扱ってはいけない。**

## ★ 決定 1: **IADR-0140 決定 4（対象は追跡下の `*.md`）を覆す**

IADR-0140 決定 4 は対象を `*.md` に限り、**残存 7 件の内訳をこう書いていた**——
「`.github/workflows/doc-links-planning.yml`（**編集不可**）1 件と、検査器の自己試験フィクスチャ 6 件」。

**「編集不可」という前提が誤っている。** `CLAUDE.md` は「`.github/workflows/` は GitHub App 権限では
編集不可」と書くが、**実測すると `.github/workflows/` は繰り返し変更されマージされている**:

```console
$ git log --oneline -3 -- .github/workflows/
4dbd501 chore(NFR): 2 回持ち越された負債を回収する（… frontend-tests.yml の paths） (#671)
ce96eb8 chore(NFR): フロントエンドに prettier の format ゲートを新設し CI へ結線する (#619)
44a3141 feat(NFR,IADR-0134,IADR-0147): manualChunks の規則構成を守る機械検査を新設し CI へ結線する (#618)
```

**「直せないから検査対象外」で残した 1 件は、実際には直せた。**
根拠が消えた以上、決定 4 は維持できない。

**検査対象を追跡ファイル全体へ広げる**（`planning` / `src/ai-stock-trading` の submodule は従前どおり除く）。
**人が読む散文は `docs/`（`.md`）だけでなく `.github/` と `deploy/` にもある** ——
#583 が「散っている」と書いた先がそこである。

## ★ 決定 2: **除外は `scripts/` のディレクトリ 1 本にする。名指しリストにしない**

IADR-0140 決定 4 の根拠 2（「`.js` / `.json` へ広げると検査器の自己試験フィクスチャで必ず落ちる。
**除外の腐りは新たな穴になる**」）は**今も正しい**。実測（是正前・develop `39d6973`）:

| ファイル | 違反 | 正体 |
| --- | ---: | --- |
| `scripts/check-cross-repo-refs.js` | 59 | **検査器自身の自己試験フィクスチャ** |
| `scripts/scripts.repo.test.js` | 3 | 同上（companion のフィクスチャ） |
| `scripts/changelog-overrides.json` | 1 | `reason` 欄が**違反を説明している**文 |
| `.github/workflows/doc-links-planning.yml` | **1** | **← 本物** |
| **計** | **64** | **63 件（98%）が「違反の文字列を書くのが仕事」のファイル** |

**名指しの除外リストにしない。** 実測で **3 ファイルへ膨らみ**、
**次に検査器を足したら静かに古くなる**（本リポが繰り返してきた型である）。

**`scripts/` を丸ごと除外する。** `scripts/` は検査器・そのフィクスチャ・baseline / overrides が
住む場所であり、**違反の文字列を書くことが仕事**である。**ディレクトリ 1 本の規則なら腐らない。**

> **★ IADR-0140 の懸念を否定していない。** 「除外の腐り」は本当に起きる。
> だから**腐りうる形（名指しの列挙）を採らず、増減しない形（ディレクトリ 1 本）を採った。**
> **`EXCLUDED_DIRS` が 1 本のままであることを自動回帰テストで固定する**（名指しリストへ戻る退行を止める）。

## 決定 3: **除外の限界を書く。黙って飛ばさない**

**`scripts/` の中の散文コメントに本形が書かれても検出しない。** これは既知の限界である。

**「検査していない」と「違反 0 件」を読み分けられるようにする**（#546 / #664 / #674 の型）——
**検査器は除外した件数を OK メッセージに出す。**

```
[check-cross-repo-refs] OK: 1510 件に他リポジトリ参照の表記違反はありません
（scripts/ の 62 件は検査していません —— 検査器のフィクスチャと baseline が住む場所であり、
違反の文字列を書くのが仕事だからである。#583 判断 2・3）。
```

## 決定 4: **`.md` の除外（インラインコード・フェンス）は `.md` 外へ持ち込まない**

`.yml` / `.js` / `.json` に「インラインコード」の概念は無い。
**`--markdown` の除外は `.md` にだけ効く**という現状を変えない。
**`scripts/` の除外（決定 2）が、その役割を代わりに果たす。**

バイナリは読み飛ばす（NUL を含むものを非テキストとみなす）。**追跡ファイル全体を対象にすると
画像等が入る**ためで、`.md` 限定では起きなかった問題である。

## 結果

- `.github/workflows/doc-links-planning.yml:6` の `ai-stock-trading #104` → **`AST#104`**（**本物の 1 件**）
- `scripts/check-cross-repo-refs.js`: `trackedFiles()` を新設（`trackedMarkdown()` は後方互換で残す）、
  `EXCLUDED_DIRS` / バイナリ skip / 除外件数のログ
- 走査は **619 件（`.md` のみ）→ 1510 件**（追跡 1572 − `scripts/` 62）。**違反 0 件**
- `scripts/scripts.repo.test.js`: 6 件追加。**#664 由来の下限テストの正規表現も追随させた**
  （OK メッセージの文言が変わったため。**兄弟の取り残しを作らない**）

### 変異試験

| # | 内容 | 装置 |
| --- | --- | --- |
| M6 | **走査が `.md` だけへ戻ったら落ちる** | OK メッセージの走査件数に下限（> 1000）を置く。**件数リテラルで固定しない** |
