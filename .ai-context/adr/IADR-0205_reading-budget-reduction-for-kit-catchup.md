# IADR-0205: 必読規約の減量とキット追随（#793）

- 状態: Accepted
- 日付: 2026-08-16
- 決定者: claude（実装）

## 起点・関連

- **NFR**（文書統制。**当たる `NFR-xx` が無い＝場合 ②** なので無採番・環流しない）
- 実装 issue: **#793**（[IADR-0204](./IADR-0204_kit-catchup-deferral-with-expiry-ratchet.md) が置いた「期限つき保留」の期限）
- 作業仕様書: [20260816_issue-793](../specs/20260816_issue-793_reading-budget-reduction.md)

## 文脈

**キット `.claude/rules/traceability.md` が `8cae89d` で +3,002B 育った。**
そのまま取り込むと必読規約の合計が予算 51,200B を超えるため、[IADR-0204](./IADR-0204_kit-catchup-deferral-with-expiry-ratchet.md) は分類を
A → B（X・期限つき暫定）へ移して追随を保留した。**本 ADR はその期限の消化である。**

**削るべき量は「超過分 ＋ 余白下限」で機械的に決まる**（[IADR-0190](./IADR-0190_permanent-headroom-by-annexing-examples.md) 決定 4 の下限 1,000B）。
**値は書かない** —— 母数（`CLAUDE.md` / companion / キット原文）が動くたびに腐る
（[IADR-0204](./IADR-0204_kit-catchup-deferral-with-expiry-ratchet.md) が実測で 3 回動いたと記録した型）。**式と測り方だけを残す。**

## ★★ 決定 1: **減量の原資は「正本が他に在る複写」から取る。規範は 1 つも落とさない**

**[IADR-0178](./IADR-0178_claude-md-defers-to-docs-readme.md) 決定 1「重複は別紙化ではなく正本へ畳む」をそのまま適用した。**
**本 PR は別紙を 1 本も作っていない** —— 削った記述はすべて**既に正本が在る複写**であり、
別紙を作れば 3 箇所目になる（[IADR-0141](./IADR-0141_audit-rounds-and-population-drawing.md)）。

| 何を | 正本 |
| --- | --- |
| 起点 ID の種別（`FR` / `NFR` / `UC` / `SC` / `ADR`）の一覧 | **同じ必読集合の `.claude/rules/traceability.md`「起点 ID の種別」** |
| 起点 ID を残す箇所と書式（ブランチ名・コミット・コード・PR） | **同上「残す箇所と書式」** |
| 束ねの条件・判定の単位・束の上限 | `IADR-0139` 決定 1（＋**射程の正は上流ガイド §2**） |
| 必読予算の母集合・値・測り方 | 運用ガイド §8 と `scripts/check-reading-budget.js`（出典つきの複製） |
| パリティ突合の観点・周期 | 運用ガイド §11 |
| 仕様書の種別一覧 | `docs/README.md`（[IADR-0178](./IADR-0178_claude-md-defers-to-docs-readme.md) が既に畳んだ） |
| 整形の対象範囲 | `src/.prettierignore`（**本文自身が「単一情報源」と書きながら列挙を複写していた**） |

> **★★ 最大の発見は「同じ必読集合の中の二重持ち」である。**
> `CLAUDE.md` の起点 ID 表と書式リストは、**同じ 51,200B の中にある `traceability.md` の
> 完全な部分集合**だった。**予算を 2 度払っていた**ことになる。
> **正本が別集合に在る複写より、同一集合の中の複写を先に探すこと。**

## 決定 2: **「AI が行動しない記述」は入口に置かない**

**人間の関与（フェーズ計画の承認・監査のサンプリング・裁定）は入口から外した。**
[IADR-0173](./IADR-0173_annex-extraction-keeps-heading-stubs.md) 決定 2 は「別紙を読まなかっただけで成果物が壊れる規範は入口に残す」と定める。
**その反対側 —— 読まなくても成果物が壊れない記述 —— は入口の資格が無い。**
正本（運用ガイド）に在り、人間はそちらを読む。

## ★★ 決定 3: **保留のラチェットは消さず、分類の両側で効かせる**

[IADR-0204](./IADR-0204_kit-catchup-deferral-with-expiry-ratchet.md) が置いた試験は `if (!deferred) return;` で、**分類 A へ戻した瞬間に空振りする。**

- **消さない。** 消すと、次に保留するとき（B へ戻すとき）に**根拠を検査する装置ごと失われる。**
  [IADR-0204](./IADR-0204_kit-catchup-deferral-with-expiry-ratchet.md) 決定 1 は `traceability.md` 固有ではなく**キット追随一般の規律**である。
- **A の側の言明を足した**: **「A に居るなら、キット原文込みで予算内であること」**。
  これは B 側の言明の対偶であり、**どちらの分類に居ても空振りしない**。
  **将来 `CLAUDE.md` / companion を加筆して予算を割ったとき、「追随を維持できない」ことが先に鳴る。**

| 分類 | 見るもの | 破れると |
| --- | --- | --- |
| **B（X）** | キット原文込みで**予算超過**していること | 保留の根拠が消えている＝**追随すべき** |
| **A** | キット原文込みで**予算内**であること | 加筆が**追随を維持できなくしている** |

## 決定 4: **キット側の減量は環流する。ただし本 issue の完了条件にしない**

**キットが配る `traceability.md` 1 本で予算の 48.0% を占める。**
配布先はこの上に固有規約を載せるため、**配布物が育つたびに配布先が減量債務を負う**。
**運用ガイド §8 は予算の総額だけを定め、配布物の取り分を定めていない** —— これが構造の穴である。

**環流の起票案は作業仕様書 §5 に書いた**（配布物の上限を §8 へ置く提案 ＋ キット側の別紙化）。
**起票と裁定は計画リポ側の仕事であり、他リポの裁定待ちを本 issue の完了条件にはしない。**

## 決定 5: **導出値は「直す」のではなく「書かない形」にする**

本 PR に折り込んだ是正 3 件のうち 2 件は**導出値の腐り**だった。

| 是正 | 型 | 採った形 |
| --- | --- | --- |
| 引き直しの記録「5 世代分」（入口・別紙とも実体は 8） | 導出値 | **数を消した。** 「8 へ直す」は次の追加でまた腐る |
| 上流ガイドの「更新日 2026-08-15」（実体は 2026-08-16） | 導出値 | **日付を消した。** 版の権威は「射程の正は §2」という**参照の書き方**で担保する |
| 凍結の射程が `feedback/` について旧いまま | 他文書の写し | **裁定 planning#369 / [IADR-0191](./IADR-0191_rewrite-boundary-is-body-vs-frontmatter.md) の追記へ追随。** `docs/specs/` へ及ぶとは書かれていないため**両者を区別して書いた**（射程を勝手に広げない） |

**回帰試験も「数が一致するか」から「数を持たないか」へ変えた** ——
**一致検査は『揃って古い』を緑で通す**（実際に通っていた）。

## 結果

- 良い影響
  - **キット追随が着地し、`traceability.md` が分類 A（バイト一致）へ戻った**
  - **同一必読集合内の二重持ちが解消した**（起点 ID の種別・残す箇所の書式）
  - **ラチェットが分類の両側で効く**ようになり、A に戻した後も空振りしない
  - **導出値を 2 つ消した**（腐りの再発源そのものを断った）
- 悪い影響・トレードオフ
  - **`CLAUDE.md` の可読性は落ちる** —— 例（`feat/FR-012-...` 等）が入口から消え、
    `traceability.md` を開かないと書式が分からない。**同じ必読集合なので必ず読まれる**ことを根拠に採った
  - **キット土台側のデルタが増えた**（分類 B の理由欄に記録した）。**環流するまでは本リポ固有**
- フォローアップ
  - **キット `traceability.md` の減量と §8 の予算配分の環流**（決定 4。作業仕様書 §5 に起票案）
  - **`docs/specs/` の凍結射程**（[IADR-0191](./IADR-0191_rewrite-boundary-is-body-vs-frontmatter.md) の追記が及ぶか）は別途の裁定待ち

## 検出しないこと（明示する）

- **入口に残った記述が規範かどうか** —— 機械には判定できない（[IADR-0190](./IADR-0190_permanent-headroom-by-annexing-examples.md) から変わらない）
- **正本へ畳んだ先が実際に読まれるか** —— 導線（リンク）の存在までしか見ない
- **キット側が次にどれだけ育つか** —— 育てば再び余白を食う。**決定 4 が構造を直すまでは対症療法である**
