# IADR-0643: 未精読の自認を変更ファイルの文脈に限る（#2276）

> 実装リポジトリ内の意思決定記録（Implementation ADR）。1 ファイル = 1 意思決定。

- 状態: Accepted
- 日付: 2026-10-26
- 決定者: claude（#2276。依頼はコーディネーター 2026-10-26）

## 起点・関連

- 起点 issue: #2276（同型の事故 2 回目: #2270 の 1 回目のレビューと #2275 の 3 回目のレビュー）。
- 改める実装 ADR: [IADR-0538](./IADR-0538_review-floor-verdict-check.md)（決定 1 (b) と決定 2 の数え方に除外を 1 つ足す。§結果の既知の偽陽性への対処）。
- 交わらない実装 ADR: [IADR-0617](./IADR-0617_review-floor-ci-scripts-tests-as-evidence-regardless-of-restore.md)（`scripts.test.js` の代わりの根拠）。変えない。
- 作業仕様書: [20261026_2276_review-floor-unread-non-file-object](../specs/20261026_2276_review-floor-unread-non-file-object.md)。

## コンテキストと課題

- IADR-0538 決定 1 (b) は、N/N を申告しつつ精読していない自認（「全行は読んでいない」「読めていない」等）があれば赤にする。
- 次の 2 文で赤になった。どちらも N/N（16/16・9/9）を申告し、変更ファイルは読んでいた。
  - #2270（67df663e）: 「（`helm template` の描画は）出力が大きく、全行は読んでいない。」
  - #2275（b5139fe6）: 「CI の `scripts-tests` の結論は一覧から読めていない。」
- IADR-0538 §結果は、この型（変更ファイル以外について書かれた「読めていない」）を既知の偽陽性として挙げ、計画書・他リポジトリの文だけを外していた。

## 決定

### 決定 1: 3 条件をすべて満たす文だけを数えない

未精読の型に当たった文のうち、次の 3 つをすべて満たすものは数えない（`aboutNonFileObject`）。

1. 文（「。」で切った単位。引用は外す）が、変更ファイル以外の対象の語を含む: 出力・描画・ログ・一覧・結論・ジョブ・CI・check-run・実行結果。
2. その文を含む行（箇条の 1 項目。引用の中も含む）が、ファイルを指す語を含まない: 差分・diff・変更ファイル・ファイル・全文・本文・コード・テスト・試験・文書・仕様・IADR・ADR・README・ファイルの拡張子。
3. その行（引用の中も含む）が、変更ファイル（`CHANGED_FILES`）のパスも名前（basename）も含まない。

- 冒頭・「確認できたこと」・「🔍 実行できなかったこと」のどの節にも同じ規則で効く。
- 文の単位は従来どおり。行の単位は、文を含む行を新たに渡す（条件 2・3 の文脈）。

### 決定 2: 下限は緩めない

- 変えないもの: 申告の数 (a)、「下限を満たしていない」の自己申告、(c) の実行の記載、未精読の型、生成物・計画書の除外、否定の否定、IADR-0617 の代わりの根拠。
- 条件 1 が無い文（「`foo.cs` は全行読んでいない」「本文は精読していない」）は従来どおり数える。
- 条件 1 があっても、行がファイルを指す（「差分の出力が大きく…」「`git diff` の出力…」「IADR の差分は出力が大きく、全文を読めていない」）か、変更ファイルの名前を含む（「`Dockerfile` の描画が長く…」）なら数える。
- 3 条件のそれぞれを外した変異で、その条件だけが赤に保っている例が緑になることを `scripts.repo.test.js` が固定する。

### 決定 3: プロンプトに 1 行足す

- 【検証の下限】の「計画書・他リポジトリを読めないことはこれに当たらない」に、コマンドの出力・CI の一覧やログを足した。ただし同じ箇条に差分・変更ファイルの名前・ファイルを指す語があると数えることも書いた。

## 実文での測定

- MSP の PR 400 本のコメントのうち、AI レビューの本文 826 本に旧と新の検査器を当てた（未精読の違反だけを比べた。変更ファイルは各 PR の最終の差分）。
- 旧で赤 12 本、新で赤 10 本。変わったのは #2270 と #2275 の 2 本だけで、どちらも上の 2 文である。
- #2220 の「CI `scripts-tests` の結果は `gh run list` の先頭 8 件に出ておらず、読めていない」は赤のまま残る。同じ行に `scripts.test.js`（拡張子）があり、条件 2 に当たるためである（安全側）。

## 結果

- #2270・#2275 の型で claude-review が赤にならない。再実行の枠を食わない。
- 残余:
  - 同じ行にファイルを指す語があると、出力・一覧についての文でも数える（#2220 の型）。行を分けて書けば避けられる。偽陽性へ倒す（IADR-0538 と同じ）。
  - 変更ファイル以外の対象の語を足して変更ファイルの未精読を隠す書き方（「`foo` の出力は…」で `foo` が拡張子なしで変更ファイルに無い名前）は捕まらない。自認を書かずに N/N と申告する嘘が捕まらないのと同じ限界である（IADR-0538 §結果）。
