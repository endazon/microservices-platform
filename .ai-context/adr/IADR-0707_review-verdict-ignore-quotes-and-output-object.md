# IADR-0707: 下限の自己申告から、引用と出力の文を外す

> 実装リポジトリ内の意思決定記録（Implementation ADR）。1 ファイル = 1 意思決定。

- 状態: Accepted
- 日付: 2026-11-08
- 決定者: claude（依頼はオーケストレーター 2026-11-08）

## 起点・関連

- 起点（同型 2 回）: #2512 の 2 回目の AI レビュー（run 42396353370）と AST#1597 の 3 回目（run 42382006516）。どちらも変更ファイルを全部読み、
  N/N を申告していたのに `claude-review` が下限の違反で落ちた。再実行で通った（言い回しが変わったため）。
- 前提: [IADR-0538](./IADR-0538_review-floor-verdict-check.md)（下限と検査器）・[IADR-0643](./IADR-0643_review-floor-unread-non-file-object.md)（変更ファイル以外の対象の除外）。
- 作業仕様書: [20261108_review-verdict-ignore-quotes](../specs/20261108_review-verdict-ignore-quotes.md)。AST にも同じ直しを入れる（AST の IADR-0643）。

## コンテキストと課題

- #2512: 「試験が固定する 5 語句（流用しない・…・前回以後だけは満たさない・M の数え方）は prompt に存在する。」。`findFloorAdmissions` は
  インラインコード・「」・『』の中を外すが、括弧の中は外さない。同じ行の「【検証の下限】」と合わさって「下限を満たしていないと書いている」になった。
- AST#1597: `helm template` の行の「他の Worker の出力は全行を読んでいない。」。IADR-0643 決定 1 の除外は**行**を単位にファイルを指す語を見るので、
  行に並ぶコマンドの引数（`values-cloud.yaml` 等）で外れる。本リポの検査器でも同じ本文は赤になる（実測）。

## 決定

1. 引用の外し方（`stripQuotes`）を `findFloorAdmissions` と `findNotReadAdmissions` で共有し、次を足す。
   - 引用ブロック（行頭 `>`）の行は数えない。
   - **語句を紹介する括弧**（直前が「語句・文言・文字列・フレーズ・表現」）の中は数えない。括弧一般は外さない
     （「下限は満たしていない（時間切れ）」の補足や、「（`helm template` の描画は）」の主語を消さないため）。
2. 未精読の判定に除外 `aboutOutputAsObject` を足す。次を**すべて**満たす文だけを外す（単位は文）。
   1. 当たった型のすべてで、一致の直前が「出力・描画・描画結果・ログ・実行結果」＋「は・を・も・の」で終わる（読んでいない物が出力そのもの）。
   2. 文（引用の中も含む）が `FILE_TARGET`（差分・ファイル・本文・テスト・拡張子 等）を含まない。
   3. 文（引用の中も含む）が変更ファイルのパスも名前も含まない。
3. 既存の除外（IADR-0643 決定 1・4、IADR-0661）と既存の試験は変えない。必須チェック名・起動条件も変えない。

## 代替案

- **括弧の中を一律に外す**: 採らない。本当の申告の補足（「下限は満たさない（時間切れ）」）や、括弧で書いた主語を消し、下限が緩む。
- **IADR-0643 の除外の条件 2・3 を行から文へ移す**: 採らない。「`foo.cs`: 描画した。出力が大きく、全行は読んでいない。」のように、文だけでは
  読んでいない物が分からない形まで外れる。直前の語で「読んでいない物が出力そのもの」と読める文に限った。
- **プロンプトで書き方を縛る**: 採らない。レビューの言い回しは回ごとに揺れ、再実行で通るという今の形と変わらない。

## 結果

- 試験: `check-review-verdict.js --self-test`（陰性 7・陽性 11 の例）と `scripts.repo.test.js`（#2512・AST#1597 の実本文の fixture、陽性の書き換え 4 通り、
  直しを外した変異で実本文が赤に戻ること）。
- 残余: 語句の括弧の語（5 語）と出力の語（5 語）は実文から取った。新しい言い回しの偽陽性は、同型 2 回で足す。
