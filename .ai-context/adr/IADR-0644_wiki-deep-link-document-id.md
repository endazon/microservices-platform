# IADR-0644: SC-04 の深いリンクの同一性を文書 ID にする（#2108）

> 実装リポジトリ内の意思決定記録（Implementation ADR）。1 ファイル = 1 意思決定。

## 決定

### 決定 1: ページを指す鍵は `doc=<documentId>` だけ

- 画面（SC-04）のページツリー・検索結果のリンクは `?doc=<documentId>` にした。出典・文書詳細・本文の中のページ間リンクは元から `doc=`。
- `doc` と `page` が同時に来たら `doc` が勝ち、URL から `page` を外す（`replace`）。
- 開いているページの現在地も `doc` で決める。

### 決定 2: 旧形式の `?page=<slug>` は互換で解決する（ADR-0091 決定 2 の実装の裁量）

- ADR-0091 決定 2 は、旧リンクの扱い（無視するか、引き直すか）を実装に任せている。本 IADR は「slug で引き、1 件に決まって開けたら URL を `?doc=<その文書 ID>` へ書き換える」を採る。
  - 書き換えは `replace`（履歴を増やさない）。検索語 `q` は保つ。
  - 開けない（不存在・権限外・同じ slug が複数の文書に一致）ときは 404 の中立表示のまま書き換えない。
- 後段 `GET /wiki/pages/{slug}`（と BFF の中継）は残す。**同じ slug の行が 2 つ以上あれば 404**（ADR-0091 決定 2）。
  - 数えるのは状態・権限を問わない全行。権限内の 1 件だけを返すと、同名の権限外の文書があるかが 200 / 404 の違いで漏れる。
- 改題した文書の旧形式の URL は、古い slug を今持つ行が無ければ 404 になる。これは従来と同じである。

### 決定 3: slug の索引は一意でない（ADR-0091 決定 1）。決定 2 と同じ変更で入れる

- `IX_Pages_Slug` を一意でない索引として作り直す。名前は変えない。slug での引き当て（決定 2）の速さのために、索引そのものは残す。
- ADR-0091 フォローアップ 1 のとおり、索引を落とす変更と決定 2（複数一致で返さない）を同じ変更に含めた。順序を逆にしない。
- slug の候補列と選び方（IADR-0541 決定 1・2）は残す。新しい slug は引き続き他の文書と違う値を選ぶので、旧形式の URL はほとんどの場合 1 件に決まる。
  並行の同期で同じ候補を選んでも保存は通る。その slug は旧形式の URL では開けないが、文書 ID の深いリンクでは開ける。
- 保存時の `IX_Pages_Slug` の 23505 を扱う分岐・`WikiPage.ReassignSlug`・計数の理由 `slug_conflict` は外した。一意でない索引では起こり得ない（起こり得ない場合への防御を残さない）。

## 理由

- ADR-0091 は利用者裁定（Accepted）で、同一性を可変の値（題名由来の slug）に置いたことが原因だと結論している。IADR-0541 の接尾辞は衝突を消すが、改題で `page=` が切れる問題を解かない。
- 旧形式の URL は既に共有されている。無視すると共有済みのリンクが全部「選ばれていない」画面になる。slug で引き直して新形式へ書き換えれば、次に共有される URL は `doc=` になる。

## 結果

- 同名の文書が 2 件あっても両方が保存され、文書 ID で開ける。
- 改題しても `doc=` の URL は切れない。
- PoC の配備: wiki-service の起動時の `MigrateAsync` が、マイグレーション `MakePagesSlugIndexNonUnique`（`IX_Pages_Slug` の作り直し）を当てる。データの移行・再同期は要らない。既存の slug の値は変えない。
- 残余:
  - 旧形式の URL は、同じ slug を持つ行が 2 つ以上になった時点で開けなくなる（404）。新しい slug は候補列で別の値を選ぶので、起こるのは並行の同期で同じ候補を選んだときか、人手で同じ値を書いたときだけである。
  - Down のマイグレーション（一意へ戻す）は、同じ slug の行がある DB では失敗する。戻すなら先に重複を解く。
  - 旧形式の URL は、書き換えの前に slug の経路で 1 回取得する（往復が 1 回増える）。
- 計画への環流（ADR-0091 フォローアップ 3）: slug の経路は残し、複数一致は 404 を返す。旧リンクは 1 件に決まれば `doc=` へ書き換える。PR の後に planning へ起票する。
