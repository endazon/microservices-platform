# 作業仕様書 — NFR の採番の宣言を `NFR-01`〜`NFR-28` へ

## 目的と射程

`.claude/rules/traceability.repo.md`「起点 ID の種別（固有）」の「`NFR` の採番は `NFR-01`〜`NFR-27`」を、計画の実物に合わせて
`NFR-01`〜`NFR-28` へ広げる。内訳を持つ別紙 `docs/how-to/plan-id-range-history-annex.md` §4 と、入口の文言を固定している回帰テスト
（`scripts/scripts.repo.test.js`）を追随させる。#1519 の作業仕様書 §射程外 が記録した宿題（`NFR` の実物 [1, 28] に対して宣言が古い）を閉じる。

**`NFR` は実在性を検査しない種別であり（同節）、値域検査・CI の判定は変わらない。** 判断を伴う決定は無いため IADR は起こさない。
