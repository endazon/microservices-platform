# 作業仕様書 — SC-19 のリンク作成 UI（#2343）

> 本仕様書は実装着手前に作成した（着手 2026-10-30。develop `c2e486c4`）。親 #2107（分割の B）。祖 #2047（指摘 M-10）。

## 計画（確定済み）

`05_screens` §SC-19「リンク作成 UI」（FR-17・ADR-0034 決定 8）は、次を定める。

- 個人資料から他の文書へリンクを張る操作では、**補完候補を作成者の ABAC スコープ内に限る**。権限外の文書のタイトルを候補に出さない。
- リンク作成時に、リンク先の閲覧権限を検証する。権限がなければ辺を作らない（後段は実装済み。両端の read、起点の write。不可視・不存在はすべて 404）。
- 検証に失敗したときの文言は「**見つかりません**」に統一する。「権限がありません」とは出さない。
- ヘルプ文言（リンク切れと権限なしは区別できない）は SC-19 に既にある。

ADR-0034 決定 8 の具体化は、終点に読み取り、起点に write を要求する（ADR-0059 決定 1）。ADR-0061 決定 4 は、グラフの露出を OFF にした個人資料のノードを撤収する（辺も消える）。

## コーディネータの拘束（2026-10-30）

1. 候補は作成者の ABAC read スコープ内に限る（存在秘匿。ADR-0034 決定 2・8）。
2. 自分の個人資料を候補に出すなら、他人の個人資料が出ない経路であることを試験で固定する。
3. 計画に書かれていない新しい公開の口を足すなら、IADR に根拠を書く。計画の判断が要るなら planning へ起票して止める。

## 現状（develop で確認）

- BFF `POST /bff/graph/edges` は #2344 で入った（透過。201・400 `unknown_edge_type`・404・409 `edge_exists`・502）。
- 辺の型の一覧 `GET /bff/graph/edge-types`（認証のみ）は在る。
- **一般利用者が表題で文書を引ける口は無い**（`/bff/documents` の一覧は管理者・運用者だけ。`/bff/search` は本文の検索）。
- グラフのノードは表題と ABAC 属性の複製を持つ（`GraphDocument.Title`・`Attributes`）。
  - ノードが無い文書（グラフの露出 OFF の個人資料・`graph_exposure = excluded`・アーカイブ・未同期）は辺の端点にできない。後段が 404 を返す。
- SC-19 の行操作に「共有先を変更する」「削除する」が在る。ヘルプ文言も在る。

## 方針（IADR-0655）

1. **候補の供給元はグラフのノードにする**（GraphService `GET /graph/link-candidates?q=&limit=`）。
   - 辺の作成と**同じスコープ（read）・同じ述語（`AuthorizedNode.Authorize`）**で絞る。候補の集合は「終点として受け付けられる文書」と一致する。
   - 個人資料は **呼び出し主体が所有者のものだけ**を候補にする（`owner` が主体名と一致）。共有された他人の個人資料も出さない。機械の主体には個人資料を一切出さない（ADR-0034 決定 9）。
   - 表題の部分一致（大小を区別しない）。`q` は 2〜200 文字、`limit` は既定 20・上限 50。
   - 返すのは文書 ID・表題・個人資料かどうかだけである。**件数・総数・打ち切りの印は返さない**（ADR-0100 の利用者検索と同じ形）。
   - 走査は更新の新しい順に一定数（2,000 ノード）で打ち切る。打ち切っても何も返さない。
2. **BFF `GET /bff/graph/link-candidates`**（認証のみ。ロールの門は置かない）。後段の状態と本文を透過する。
3. **SC-19**
   - 利用中タブの行操作に「リンクを張る」を置く。ダイアログで次を行う。
     - 辺の型を選ぶ（`/bff/graph/edge-types`）。
     - リンク先を表題で探す（2 文字以上・300ms のデバウンス）。
     - 候補を選んで「リンクを作成」を押す。
   - 自分自身（起点の資料）は候補から除く。
   - 🔴 **グラフの露出が OFF の資料では押させない**。ノードが無く、必ず 404 になるためである。理由を文言で示す。
   - 応答の文言:
     - 201 は「リンクを作成しました。」
     - 404 は「見つかりません。」（「権限」の語を出さない）
     - 409 `edge_exists` は「このリンクはすでにあります。」
     - 400 `unknown_edge_type` は「選んだリンクの種類は使えません。」
     - その他は後段の理由。
   - 成功したら、起点の近傍（SC-18 の照会）のキャッシュを無効にする。
4. **文書**:
   - SC-19 の画面仕様書・テスト仕様書
   - BFF 境界
   - openapi
   - FR-17 の機能仕様書（候補の口）
