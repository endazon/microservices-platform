# 作業仕様書 — SC-09 から SC-12 への導線（#2123）

> 本仕様書は実装着手前に作成した（着手 2026-10-26）。親は #2047（指摘 M-24 の SC-09 → SC-12）。

## 現状（origin/develop で再確認）

- 計画の画面遷移図は `SC09 --> SC12[SC-12 MCPクライアント登録管理]` を描く（`05_screens/01_screens.md` §画面遷移）。
  hi-fi モック（`mockups/hi-fi/sc-09.html` 418）は区画の切替の行の右端に「MCPクライアント管理 →」を置く。
- 実装の SC-09（`AdminAbacSettingsPage.tsx`）にこの導線が無い。試験は「遷移先の画面（MCP クライアント管理）が未実装（#445 待ち）のリンクを置かない」として不在を固定している。
  画面仕様書（§hi-fi 対応 #5「しない」）とテスト仕様書（#16）も同じ理由で不在とする。
- **その理由は失効している。** SC-12 は実装済みである（`sc12McpClientsRoute.tsx`。ルート `/admin/mcp-clients`）。
- アクセス制御: SC-09・SC-12 とも管理者だけである（どちらのルートも `RequireRole anyOf=[Admin]`）。導線を見られる人は遷移先も開ける（押すと NotFound になる導線ではない）。

## 方針

- SC-09 の見出しの行の右端に MCP クライアント登録管理への導線（`Link to="/admin/mcp-clients"`）を置く（モックの位置に寄せる）。
  文言は左ナビ・遷移先の見出しと同じ既存の「MCP クライアント登録管理」を使い、矢印は読み上げない飾りにする。
  新しい文言を足すと ja / en の訳が入口チャンクのカタログに入り、初期ロードの床を割った（+0.08 kB。実測）ため。
- 試験を反転する。リンクがあり、押すと `/admin/mcp-clients` へ遷移する（ルーターの位置で確かめる。試験から SC-12 の feature を import しない ——
  feature 間の import は lint の zones が禁じる）。
- 画面仕様書（§hi-fi 対応 #5 を「する」へ、§実装しない要素の該当行）とテスト仕様書（#16）を改める。
