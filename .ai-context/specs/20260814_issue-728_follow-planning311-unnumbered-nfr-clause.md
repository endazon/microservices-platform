# 作業仕様書: planning#311 への追随（#728）

## 起点

- **NFR**（文書統制。**該当する `NFR-xx` が無い作業＝場合 ②** なので無採番。**本 PR が取り込む当の条文に従っている**）

- 出所: **PR #727（#724）のマージ直後、利用者の指示で planning の更新を確認した際に検出**

> **★ 値の基準時点は develop `39dd95b` / planning pin `915981a`（2026-08-14 実測）である。**

**planning#311 は 2026-08-11 に裁定され、結果がキットの `.claude/rules/traceability.md` へ入っている。
本リポの入口が追随していない。**

> **裁定 1: 「当たる番号が無ければ無採番」という読みで相違ないか → 相違ない。実装側の読み（`IADR-0179`）を追認する**

**結論は一致しており実装上の誤りは無い。** **しかし [IADR-0188](../adr/IADR-0188_unnumbered-nfr-applies-to-all-work.md) は planning#311 を引用していない。**
**着手前にキット本文を読んでいれば分かった。** **#721 と同型である**（pin は進んだが、キットの本文を読みに行っていない）。

## 判断

### 判断 1: **キットを逐語コピーせず、規範だけを取り込む**

**入口は分類 B/C であり、バイト一致の対象ではない。** **取り込むのは規範であって文章ではない。**
**削った 1,525B − 実際の増分の差は、キット原文が持つ理由・典型例の説明である**（本リポは別紙と ADR が持つ）。

### 判断 2: **既存の #688 / #724 の記述と統合する。並置しない**

**場合 ② は #724 が一般化した内容そのものである。** **並べると同じ規範が 2 つになり、片方が古くなる**
（[IADR-0141](../adr/IADR-0141_audit-rounds-and-population-drawing.md)）。**1 つの箇条へ畳む。**

**#724 の回帰テストが固定する 4 文字列はすべて保持する** ——
`該当する \`NFR-xx\` が無い作業は無採番 \`NFR\` を使う` / `メタ作業（規約・検査器・文書統制）は代表例` /
`製品の作業にも当たる番号が無いことはある` / `無いことは「実装側で作ってよい」ではない`。

### 判断 3: **ID 種別名は `NFR` のままとし、理由を記録する**

**キットは `NFR-xx` と書くが、本リポは既存参照が一律 `NFR` である。**
**planning#295 が遡及書き換えを禁じており、種別名を `NFR-xx` に変えると
「裸の `NFR` は種別として存在しない」と読める。** **箇条の側で採番の実在と 2 場合を書く**ことで、
キットの意図（粒度なしを既定にしない）は満たす。**固有デルタとして記録する。**

### 判断 4: **IADR-0188 へ日付つき追記で planning#311 を引用する。決定は変えない**

**独立に同じ結論へ至ったことと、上流の裁定に従ったことは、記録として区別する価値がある。**
**決定内容は正しいので覆さない。** **引用の欠落だけを是正する。**

### ★ 判断 5: **恒久的な余白の確保は本 PR では行わない。ただし「同型 2 回」に達したことを記録する**

**#724 と本 PR の 2 連続で、入口へ規範を足すために捻出を強いられた。**
`CLAUDE.md`「検査器・規約の追加は同型の事故が 2 回起きたら」の**2 回目**である。
**本 PR では別 issue として起票するに留める**（節の別紙化は規範の射程に触れる作業であり、別の判断が要る）。
