## 起点となる計画書（トレーサビリティ）

- 機能要求（FR）: **FR-17**（関係の種類と出所を区別して保持する）
- 関連 ADR: **ADR-0034 決定 8**（**個人資料から権限外文書へのリンクは張れない。リンク作成時に権限を検証する**）/ ADR-0033 決定 4・5・6
- 実装 ADR: **IADR-0242**（決定 6・9。新規 IADR は起こさない）

## 対象範囲

### 対象

`POST /graph/edges` —— 利用者が明示的に辺を付与する。出所は `user` 固定。

### 対象外

辺の削除・更新（所有規則が要るが `owner` が未充足。§未強制 を参照）、イベント連携、BFF 公開。

## 設計

### 到達可能性の検証（本単位の中核）

`ADR-0034` 決定 8 は「リンク作成時に権限を検証する」と定める。**検証しないと、辺を張る行為そのものが
権限外文書の存在を確かめる手段になる** —— 張れたら在る、張れなければ無い。

したがって:

1. **両端を検証する。** 終点だけ見ると、見えない文書を起点にして辺を生やせてしまう。辺の可視条件
   （両端が許可。`IADR-0242` 決定 6）と作成条件を揃える
2. **不可視・不存在はすべて 404。403 にしない。** 403 は「権限が無いだけで存在はする」ことを漏らす。
   読み取り側（`GET /graph/{id}`）と同じ線を引く
3. **型の実在は 400。** 文書の可視性とは無関係な入力誤りであり、404 にすると型の実在が文書の存在秘匿と
   混ざって読めなくなる

### 契約で受け取らないもの

- **出所（provenance）** —— この経路で作られる辺は必ず `user` である。呼び出し側に選ばせると
  自動抽出や AI 承認済みを騙れる（出所は `ADR-0033` 決定 4 の区別の根拠である）
- **アンカー** —— 粒度は文書単位（決定 5）で、チャンク粒度は Phase 3 の予約である。受け取れるように
  すると、予約列が「使ってよい欄」として先に埋まる

### 重複

`ADR-0033` 決定 6（同じ関係を二重に持たない）。対称型は `Edge.Create` が `(min, max)` へ正規化するので、
**逆向きの再作成も同じ 1 行として弾かれる**（`IADR-0242` 決定 9）。

## 受け入れ基準

- [x] 権限外文書へのリンク作成が 404（403 でない・不存在と**本文まで**区別できない）
- [x] 起点が権限外でも 404（終点だけ見ない）
- [x] 作成された辺の出所が `user`
- [x] 未定義の型 ID が 400
- [x] 自己ループが 400
- [x] 同一の (source, target, type, anchor) の重複作成が 409
- [x] 対称型の逆向き再作成も 409
- [x] スコープ無しは 404 / 未認証は 401

## 変異試験の実走結果

手順は #909 / #910 と同じ（変異 → バックアップとの差分を生で読む → **ビルド成功 EXIT=0 を先に読む** →
テスト結果 → 復元し差分 0 を確認）。

| 変異 | ビルド | 落ちたテスト |
| --- | --- | --- |
| **U-1** 到達可能性の検証を丸ごと外す | 成功 0 警告 | **3 件**（終点・起点・区別不能性） |
| **U-2** 終点だけ検証する（起点を見ない） | 成功 0 警告 | 起点が権限外のケース |
| **U-3** 不可視を 404 ではなく 403 にする | 成功 0 警告 | **3 件**（403 は存在を漏らす） |

**U-2 が 1 件だけ落ちるのが要点である。** 「終点だけ見る」実装は、終点の否定形テストだけでは
**素通りする**。起点側の否定形を別に置いてあるから捕まる。

否定形には陽性対照（両端が見えれば 201 で作成できる）を対で置いてある。

## ⚠ 検証できていない範囲

**重複防止で効いているのはアプリ層の事前検査だけである。** InMemory プロバイダは一意索引を強制しない
ため、DB 層の `ux_edges` が働くことは本単位では確認できていない（#941 で確認する）。
競合（検査と保存の間に同じ辺が入る）を 409 へ変換する分岐も、一意制約が効かないと発生しないので
**通っていない**。

## 計画書との差異

- 差異: **あり**（いずれも既知・新規の環流は起こさない）

1. **辺の削除・更新を実装していない。** 所有規則（自作のみ削除できる等）は `owner` 属性が実データ
