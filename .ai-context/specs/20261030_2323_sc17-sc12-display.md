## 方針

1. **SC-17**: 副題の近くに、ABAC 設定（`/admin/abac`）への内部リンクを置く。文は「割り当てられる属性の値は ABAC 設定（属性体系・タグ辞書）で定義します。」とする。
   - SC-09 と SC-17 はどちらもシステム管理者（`platform-admin`）だけが開ける（計画 §共通シェル）。導線で新たに見せるものは無い。
2. **SC-12**: 公開ツール一覧の表に「説明」「必要スコープ」「送信可否分類」の列を足す。
   - 計画 §SC-12 は一覧を「実効構成の参照」とし、実効構成の項目は 11_mcp-server-integration §公開構成（`required_scope`・`egress_class`）が定める。契約が既に運ぶ値を描くだけで、操作は足さない（参照専用・GitOps への誘導は変えない）。
   - 値は識別子のまま出す（`document:read`・`metadata-only` 等）。表示名の辞書は計画に無いので作らない。

## ［2026-10-30 追記］a11y の回帰を直した（#2328 の e2e a11y.smoke）

- CI の `a11y.smoke` で、本 PR が持ち込んだ axe の違反が 2 種あった（手元の Playwright でも再現した）。

- 直し方（baseline は更新していない）:
  - `@platform/ui` の `Table` に任意の `scrollRegionLabel` を足した。渡すと受け皿が `role="region"`・`tabIndex=0`・`aria-label` を持つ。渡さない表は従来どおり（タブ位置を増やさない）。既存の同型箇所は無かった（`grep -rn "overflow-x-auto"` で `Table` の受け皿だけ）。見出しへの `aria-labelledby` は `Panel` の見出しが id を持たないので、表の caption と同じ文言の `aria-label` にした。
  - SC-12 の公開ツール一覧が `scrollRegionLabel` を渡す。
  - SC-17 のリンクに常時の下線（`underline`）を付けた。
- 試験: `layout.test.tsx` に受け皿の 2 本（渡すと名前つきの領域でフォーカスできる・渡さなければ領域でもタブ位置でもない）。手元の Playwright で e2e 全体 216 本が緑（a11y.smoke の SC-12・SC-17 の 3 本は修正前に赤を再現）。
