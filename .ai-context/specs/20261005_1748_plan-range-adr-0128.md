# 作業仕様書 — 計画 ADR レンジを `ADR-0001..0128` へ

## 目的と射程

`.claude/rules/traceability.repo.md`「起点 ID の種別（固有）」節の計画 ADR レンジ宣言を `ADR-0001..0124` → `ADR-0001..0128` へ更新する。
計画側に次の 4 件がマージされた。これらを引く作業（#1746 = ADR-0127 の実装、#1747 = ADR-0128 の見直し条件）が件名・trace ブロックで引けるよう、前回（#1612 / #1613、#1682 / #1684）と同じ形で開ける。

- ADR-0125（AST の KB 読み手 1 本に限り projects × project の静的ポリシー対を置き、機密区分の上限を加える。planning#714）
- ADR-0126（データソースの資格情報は SC-22 の群から投入し、管理者だけが書け、供給元は「画面（実行時に取得）」。planning#717）
- ADR-0127（高機密文書は埋め込まず全文索引だけで検索し、再順位付けと回答生成は Claude。ADR-0017 を置き換え。planning#719）
- ADR-0128（LLM ゲートウェイは自前を維持し OSS 製品は採らない。見直し条件 3 つ。planning#721）

**射程はレンジ宣言 1 行と別紙への 1 回分の追記に限る**。判断を伴う決定は無いため IADR は起こさない。

**射程外**: ADR-0017 が `Superseded`（by ADR-0127）になったことに伴う、本リポジトリの ADR-0017 引用（`.ai-context/specs/`・`.ai-context/superpowers/` を除き 40 ファイル）への後継併記（traceability.repo.md §Superseded / Deprecated な ADR を引用するときの書式・#580）。ADR-0127 を実装する #1746 が持つ。本回は別紙に状態遷移を記録するに留める。
