# 仕様書: 稼働 PoC のバックアップが停止中であることを明記する（#1709）

## 起点（トレーサビリティ）

- #1709（監査 2026-10-01・high）: #1700 で platform-backup の CronJob 2 本は前提（イメージと age の受取人）が揃うまで
  `suspend: true` になった。稼働 PoC はバックアップを 1 本も取れていないが、#1699 は閉じ、`docs/operations/operations.md`
  §バックアップ・リストアには方式の表しか無い。起動時の WARN 1 回だけでは放置が見えにくい。
- NFR-21（バックアップ）・IADR-0471（日次の暗号化バックアップ）。計画 ADR の新たな制約は無い。

## 範囲

本 PR は **文書で現状を見えるようにする**部分だけを扱う。次は利用者の操作か別作業であり、#1709 で引き続き追う。

1. age の受取人を作る（利用者）。
2. イメージを作り直す（資格情報ヘルパーの回避を含む。原因の判定は #1689 の `backup-image-build-cause.sh`）。
3. `k8s-local-up.sh` を再実行して有効化する。
4. 手動 Job を 1 回走らせてリストア試験を行う。

## 母集合（規則 9）

「バックアップが動いている」と読める記述を `バックアップ|backup` で `docs/` を走査して引いた。

| 文書 | 該当 | 扱い |
| --- | --- | --- |
| `docs/operations/operations.md` §バックアップ・リストア「ローカル環境で稼働しているもの」 | 「日次で … 置く」と現在形で書く | 直後に「現状: 停止中」の 1 項を足す |
| `docs/operations/platform-infra-backup-runbook.md` §2 日々の確認 | 手順 0 は「有効か」を確かめるだけ | 手順 0 の前に現状の注記を置く |
| その他（設計・テスト仕様の記述） | 方式の説明で、稼働状態を主張しない | 触らない |

## 窓（規則 11）

該当しない。時刻の差を扱う是正ではなく、現状の明記だけである。注記には「再開を確かめたら消す」を書き、消し忘れ（文書が古い現状を言い続ける側）を防ぐ。
