# 作業仕様書 — 取引ユニットのボット専用のロール（#2441）

> 着手 2026-11-06（develop `0f3bda2d`）。新しい IADR は作らない（AST 側の判断は AST/IADR-0622。基盤側はレルムの宣言を足すだけ）。

## 起点

- #2441（AST#1554 の段 ②）。AST/IADR-0622 は、AST の提供側が `trading-bot` を、ボットのクライアント（`ai-stock-trading-owner`）かつボットの許可表の経路と gRPC の所有者の面でだけ受け入れる、と決めた。
- 正本は基盤レルム（`deploy/keycloak/microservices-platform-realm.json`）で、AST 専用レルムはその写し（AST/ADR-0038 決定 3・IADR-0434）。AST の写しは AST#1555 で段 ② の形になっている。

## 要件

1. realm ロール `trading-bot` を足す。
2. `service-account-ai-stock-trading-owner` の realm ロールに `trading-bot` を足す。`trading-owner` は**外さない**（外すのは段 ⑤ で、別の PR）。
3. 他のクライアント・利用者には付けない（複合ロール経由も含む）。
4. 写しの突合（`check-realm-copy-drift.js`）を差分 0 件に保つ。そのために、submodule `src/ai-stock-trading` を同じ PR で AST develop の先頭（`c322b26d`。AST#1555 と AST#1558 を含む）へ進める。
   - submodule だけを進めても、レルムだけを変えても、突合は赤になる（実測）。だから 1 本にする。
   - AST#1558 は、イメージのビルド時の Wolverine の codegen が AST#1546 の守りで止まっていた件の是正である（#2463 の Images の赤の原因）。

## 方針

- 既存の realm へは、調停（`reconcile-realm.js`）が当てる。1 回目に `role.create` を行い、サービスアカウントへの割当はロールが出来るまで `deferred` になる。2 回目に `user.realmRoles.add` で `trading-bot` だけを足す。新しい分岐は要らない。
- 通信は止まらない。段 ② の後もボットは `trading-owner` を持つ。AST の古い版は、増えたロールを無視するだけである。
- submodule の範囲は `e3254f03..c322b26d`（first-parent で 22 コミット）。そのうち `e3254f03..1cc3f395` の 20 本に MSP 側で合わせる変更が無いことは、#2463 で確かめた。残りの AST#1558 は Dockerfile の codegen の行だけ、AST#1559 は CHANGELOG だけで、これも合わせる変更は無い。

## 受け入れ基準

- AC-1: 実データの realm で、`trading-bot` を持つのはボットのサービスアカウントだけで、複合ロール経由も無い（`keycloak-realm-reconcile.test.js`）。
- AC-2: 段 ② の前の稼働 realm へは、ロールを作ってから `trading-bot` だけを足し、外す操作を出さない（同上）。
- AC-3: `check-realm-copy-drift.js` が差分 0 件、`check-realm-constraints.js` が OK。
- AC-4: submodule の build が通り、既存の試験が通る。

## 残る制約

1. **調停はサービスアカウントの realm ロールを外さない。** 欠けているものだけを `user.realmRoles.add` で足す（`reconcile-realm.js` のサービスアカウントの分岐）。段 ⑤ で宣言から `trading-owner` を消しても、稼働の realm からは外れない。**段 ⑤ には、外す経路（調停の改修か、手で外す手順）が別に要る。** どちらにするかは段 ⑤ で決める。
2. **既知**: integration-stack の TLS の門の注記「取引ユニットは AST の chart の切り替えまで平文のまま」は、本 PR で古くなる（AST が TLS へ切り替わる）。門は AST の接続を数えるだけで判定しないので、結論は変わらない。
