## 下限を緩めないこと（IADR-0538・IADR-0617 の確認）

- IADR-0538 決定 1 (b): N/N を申告しつつ、読んだと申告したファイルを精読していない自認があれば赤。決定 2: 🔍 の節も読むことの自認の型に限って数える。
- IADR-0538 §結果は、この偽陽性（🔍 の節の「読めていない」が変更ファイル以外を指す）を既知のトレードオフとして挙げ、「他リポジトリ」「計画書」の文を外すことで対処していた。本件はその除外の型を「コマンドの出力・CI の一覧」へ広げる。
- IADR-0617 は `scripts.test.js` の代わりの根拠（CI の scripts-tests の success）の決定で、本件と交わらない。触らない。
- **緩めない範囲**（変えない）: 申告の数 (a)、自己申告 (b) の前半、(c) の実行の記載、生成物・計画書の除外、否定の否定。
- 新しい除外は、次の 3 つを**すべて**満たす文だけに効く。
  1. 文（「。」で切った単位）が、変更ファイル以外の対象の語（出力・描画・ログ・一覧・結論・ジョブ・CI・check-run・実行結果）を含む。
  2. その文を含む行（箇条の 1 項目）が、ファイルを指す語（差分・diff・変更ファイル・ファイル・全文・本文・コード・テスト・試験・文書・仕様・IADR・ADR・README・ファイルの拡張子）を含まない（**引用の中も見る** —— 初版は引用を外していたが、「`git diff` の出力が大きく…」を外してしまうため改めた）。
  3. その行が、変更ファイル（`CHANGED_FILES`）のパスも名前も含まない（引用の中も見る）。
- したがって「`foo.cs` は全行読んでいない」（対象の語が無い）・「`foo.cs` の出力が大きく、全行は読んでいない」（変更ファイルの名前）・「差分の出力が大きく、全行は読んでいない」（差分）・「IADR の差分は出力が大きく、全文を読めていない」（#1921 の型）・「本文は精読していない」（#1924 の型）は赤のまま。
