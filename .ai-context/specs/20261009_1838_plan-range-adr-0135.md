# 作業仕様書 — 計画 ADR レンジを `ADR-0001..0135` へ

## 目的と射程

`.claude/rules/traceability.repo.md`「起点 ID の種別（固有）」節の計画 ADR レンジ宣言を `ADR-0001..0129` → `ADR-0001..0135` へ更新する。
計画側で 2026-10-09 に ADR-0130（planning#745 の裁定）、planning#750 の裁定（ADR-0131 Valkey・ADR-0132 OpenBao・ADR-0133 基準 D の前段認証・ADR-0135 点検の母集合と版の即時固定）、planning#751 の裁定（ADR-0134 MCP クライアントの Keycloak の形と secret の一度だけ表示）がマージされ、宣言が 6 件遅れた。遅れの窓では `ADR-0130`〜`ADR-0135` を引く件名・trace ブロックが CI に拒否される。

**射程**: 宣言 1 箇所の数字の置換と、別紙 `docs/how-to/plan-id-range-history-annex.md` への 1 回分の追記（表・出典・契機）と trace ブロックの追随。判断を伴う決定は無いため IADR は起こさない。

**前回（#1769）との差**: 今回は `NFR` が動いていない（実物 [1, 29] のまま）。したがって NFR の採番宣言・別紙 §4 の内訳・`scripts/scripts.repo.test.js` の入口文言の固定（`NFR-01`〜`NFR-29`）は追随不要であり、触らない。

**射程外**: 新しい ADR が求める実装（Valkey・OpenBao への差し替え、前段認証、SC-12 の公開クライアント・secret 表示、Argo CD・k3s の版固定、MCP のツール検索の 2 キー AND）は本件では行わない。
